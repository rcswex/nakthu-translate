# 梦天语译写（汉 → 梦天语）

把原文译进梦天语（Nakthu，`Nāk-θụʔ`）。**信**：不替原作作证，不增不减意；**达**：每个词、每个构式都合梦天语自己的语法；**雅**：定对文体，定域即定命。

> 梦天语的词不能逐词对译，却永远可以译出：路径换不了，落点换得了。译者的活儿在这两句中间的缝里。
> —— 汇编「翻译两定律」

## 0 · 参数

调用形如 `/nakthu-translate [参数] <原文或文件路径>`。参数可出现在原文之前或之后；原文是文件路径时读该文件。

| 参数 | 输出 |
|---|---|
| （无） | **默认**：每节三层——梦天语 · 逐字译 · 落点读 |
| `-only` | **仅梦天语**：只给译文本身，不带逐字译、落点读、说明 |
| `-doc` | **文档**：写成 MD 文件，体例见 `references/output-formats.md` 的「文档模板」，保存后只回报路径与三句要点 |
| `-style=<文体>` | 指定文体（22 体之一，见 `references/translation-craft.md`）；不给则自己判定并说明 |
| `-out=<路径>` | 只对 `-doc` 有效：输出路径；默认 `<当前目录>\<题>_梦天语译.md` |
| `-root=<路径>` | 换用别的档案根目录（含 `language/`）；默认用 skill 自带的 `archive/` 快照，也可设环境变量 `NAKTHU_ROOT` |

`-only` 与 `-doc` 同时给出时按 `-doc`。无原文就问一次原文是什么，别猜。

## 1 · 先定位档案（动笔前必做）

`SKILL_DIR` = 本文件所在目录。**这个 skill 自带完整的梦天语档案快照**：`<SKILL_DIR>/archive/language/`，不依赖任何外部文件。先运行：

```
python "<SKILL_DIR>/scripts/nakthu_lex.py" where
```

（沙盒里没有 `python` 命令就用 `python3`。）它列出实际使用的档案根、各文件是否在位、新铸词列表的位置。**在 Claude Chat 这类只有代码执行沙盒、没有本地文件夹的环境里**，`-doc` 文档与 `新铸词列表.md` 要写到沙盒提供的可下载输出目录（如 `/mnt/user-data/outputs`），并用 `--temp` 指向它（`--root`、`--temp` 是全局选项，写在子命令之前：`nakthu_lex.py --temp <目录> coin …`），最后把文件交给用户。若设了 `NAKTHU_ROOT` 或给了 `-root=`，则以外部档案为准（作者的活档案可能比快照新）。档案缺失就停下来说明，**不要凭记忆写梦天语**。

**权威次序**（冲突时靠前者胜）：词法手册 > 分级词典／词典／词账 > 主书 > 汇编 > 范文。

**范例译文（遇到、至圣先师歌等）是格式范本，不是词形权威。** 其中有旧写法：旧第二人称 `tə́k` 现行改用 `nī`；`ʔaʔ` 是「强调同一」，不是中性系词，普通类别判断用停顿 `dīk, kə̄x.`。凡与词法手册、词典冲突，以后者为准。

大文件一律 `Grep` 取节，不整本 `Read`。词法手册的节标题可直接搜：`### 二 · 1　座架与判据`、`### 四 · 2　事化`、`### 四 · 5　循格`、`### 六 · 1　复杂句`、`### 六 · 2　文体`。

## 2 · 工作流

1. **读原文，认落点，不逐词**。分句、分节；标出：（a）意象（照翻）；（b）抽象词与成语（要认落点）；（c）情绪词（愁、恨、断肠类，要移位）；（d）原文明说了来路的地方（见、闻、听说、推断，才可挂判据）；（e）专名、书名。
2. **定域（文体）**。按 `references/translation-craft.md` 的文体选择表判定；一首诗只有一个基调，融合发生在词上，不发生在段上。向用户说明所选文体及一句理由。
3. **定层（ə／a／a:）**。抽象词一律取最低可用层，古人不说超越语。
4. **配弯**。对每个关键词：读出原文的弯 → 认落点 → 在梦天语里配**一条短弯**（短到能在一次工作记忆刷新内走完）。顺序：先 `lookup` 查现成词 → 再变调/变核/限定复合 → 最后才声训新铸（见 §4）。`lookup <汉字>` 只列【】栏与释义开头命中的词，查不到先换同义字、上位词、复合（如 床＝睡—木），再加 `--all` 翻释义正文，**确认真缺才算缺词**（见 §4 的 `gap`）。方位八枚（上 `hə̄t`、下 `hə̄ŋ`、内 `hə̄ɣ`、外 `hə̄x`、旁 `hə̄p`、前 `hīn`、后 `hūn`、距 `hə̄s`）在 `lookup` 里都查得到。
5. **定调、定判据**。调的六种操作各司其职；**判据默认零，加判据须有据**。
6. **起草**，保持全篇同一概念同一译词（长文先列一张本篇译名表）。
7. **校验**：把梦天语转写存成临时文件，运行
   ```
   python "<SKILL_DIR>/scripts/nakthu_lex.py" check <文件>
   ```
   `✗` 必须清零；`◇`（各素在册的复合）逐个判：命名新概念或专名 → 登记，当场的透明限定复合 → 不必；`△`（变调形）逐个回词典核；临时词线：词符 ≥ 40 的文本占比 ≤ 5%，**短文（< 40 词符）不看百分比，每篇已登记 ✧ ≤ 3 枚**，且逐枚过铸词四关，越线就回到第 4 步重配弯。再对照 §3 的硬规则与词法手册逐条自查。
8. **回译自检**：把梦天语读回汉语（只说梦天语真正说出的，不比它多一字），与原文对照，记下丢了什么、加了什么——这就是落点读与损失清单的底稿。
9. **输出**（§5）。

## 3 · 硬规则（违者即错）

**词与形**
- 每个梦天语词形必须**在册**：词典、分级词典、词账，或本次登记的 ✧。不确定就 `lookup`，不凭记忆。
- 一格一音节：一个不带连字符的书写单位只有一个韵核；多音节必带连字符（`ʃi-pə̄t` 对，`*ʃipə̄t` 错）。连字符只接音节：复合、语域前缀、零调附着，没有第四种接法。复合的中心语在末位。
- 冒号 `:` 只作长音符，**转写中不作标点**；汉译层不受此限。声调标在韵核中开口度最大的元音上。
- 专名一律**照义译、不照音**；书名、被引用的名字用 `« »`。

**句**
- 普通陈述 **SOV**（主 宾 动）。否定词 `mə̀` 放谓词之后；明确禁止用 `mà`。「不必」`… ui: mə̀`、「应当不」`… mə̀ ui:`、「禁止」`… mà` 是三个句子，别译反。
- 没有中性系词。类别判断用停顿：`dīk, kə̄x.`（这是石头），否定后置 `dīk, kə̄x mə̀.`；`ʔaʔ` 只用于「本质上就是」的强同一。存在用处所在前：`dīk-θīh-nəm lə̄s.`。
- **座架**（因 `iu`、故 `əu`、虽 `iə`、为 `əi`、即 `ei`、比如 `ui`、丧 `uə`，及含 `o` 的八枚）**分写，跟在所连的前一段之后，不居一句之首**（跨句可起新句）。模态是座架的长音形，站在谓语上。
- **判据**（亲眼 `-i:`、亲耳 `-e:`、亲身 `-u:`、闻 `-mu:`、实测 `-ui`、推算 `-əu`、直觉 `-iu`、传闻 `-ei`、不完全确定 `-iə`、预期 `-əi`、无凭之证 `-o:`）零调、连写，宿主是动词或状态词（不是名词、引号、事化内部），**只管所在分句**，否定在判据之前（`lə̄s mə̀ gə̀ɣ-ui`）。
- **事化**＝调 6 把小句收成一件事，作外层谓词的内容；事化成分内部不挂判据，来路由外层谓词交代。
- 引语 `« »`，嵌套 `‹ ›`；外层判据挂在报告动作上（`θụʔ-e:`），引号本身不是宿主。
- 疑问：句末 `kə̉`（是非），词内调 4 问那一个词；疑问句用 `?`。

**译法**
- **判据默认零**：原文没说「我见／我闻／听说／我推断」，译者不替它作证（否则把鉴赏诗改成供词）。原文明言才挂；或颂诗里「传说」之类须交代来路时挂并在译注里说理由。
- **意象照翻**：五禁例之外，不得用一个「更本地」的词换掉原文意象（琴瑟→弦件共振，红尘→有回响的尘土，尘必须留着）。**查不到词不是换意象的理由**：先配复合或登记 ✧，用 `gap` 记下缺词；万不得已才用邻近意象顶替（如以雪顶霜），那必须写进损失清单。
- **规则冲突的裁决**（文体家法、信、语法三者顶牛时）：① 语法硬规则（§3「词与形」「句」）永不让；② 其次是信：原文明言的内容不丢、不擅加；③ 文体家法最后。冲突时**先在本文体内找绕行**（例：风雅体零判据，而原文有明言的「疑」——先试能否用不挂判据的手段说清）；绕不开就**升体**（五绝由风雅体升到全盛期文学体），并在译注或校记里写明：冲突是什么、为什么升、升了之后丢了什么。不要为守一条家法而悄悄破另一条。
- **五禁例**（须转写）：农业隐喻、罗盘方位（东西→近 `i`／远 `u` 向度，或日出处／日落处）、颜色词（以物代色：白＝雪，黑＝夜）、情绪抽象名词（愁、恨、断肠：八大词无负轴，须**移位**，如 `ràx` 隐裂）、数目（手系，不借汉语数系；千进）。
- **叠字二分**：事件叠字（点点、声声）→ 象似重复（二连有界、三连无界，**没有四连**，重复不许换调、不夹别的成分）；状貌叠字（漫漫、踽踽）→ 改写为可再发生的动作，或不译重复。有语法（数词、判据）可用时不用重复。
- **不排高下**：尊卑、长幼是永久禁列。敬称只是长音（`θā-nə̄k` 教者 → `θā:-nə̄k` 老师：言而不止，不是「更高」）；不给亲属词、性别称谓造敬称。「至圣」「高山」译成「不终止」「够不着而确在」，不译成「在上」。
- **禁语**：不得写「梦天语说不出 X」「没有 X」。改写为「说 X 要拐一个弯，弯的形状是＿＿，拐完意思变了＿＿」。损失记在译者账上，不记在语言账上。
- **膨胀有选择**：抽象处压缩（一个大词或长音），具象处膨胀（二字变三音节）。

## 4 · 新铸词（✧）

这门语言不造词：合法格点读得出来，读出来就是懂。译者写出一个新词，只是「念到了一格」，没有自由，只有准不准。

**铸之前**：`lookup` 查词典、分级词典、词账、新铸词列表；撞形即并，同形不许两义。**例句不够**与**语言缺词**是两件事，后者是 ✦ 候选，另交词典编委，不在本账。

**铸词四关**：格点核查（骨架空）· 不添新簇 · 年代落位 · 听感回避。硬判：四槽读下来就是它的意思；须另附一句定义才立得住的，是私造，作废。不得为韵脚、为新奇而挑一格。

**优先路线**（能走前面不走后面）：现成词 → 变调（六调同族）→ 限定复合（本名＋限定，中心语居末）→ 变核（`ə→a→a:`）→ 声训新形。专名走「照义译」的复合。

**登记**：每枚 ✧ 词（含新立的专名复合）登记到 `_temp/新铸词列表.md`（位置依次取：`--temp`、环境变量 `NAKTHU_TEMP`、自当前目录向上第一个含 `language/` 的目录下的 `_temp`、当前目录下的 `_temp`；`where` 会报出实际路径），用：

```
python "<SKILL_DIR>/scripts/nakthu_lex.py" coin --form "xə̄p-kūx" --slots "土＋山" --gloss "尼丘" --kind 专名 --level 1 --source "《至圣先师歌》"
```

`--kind` 只能是：复合、专名、变调、变核、声训新形（其余会被拒绝）。级由形算出：四个槽逐一读，取最晚那一项资源的级（细则查分级词典各级「本级资源」）。撞形两义会被脚本拒绝。登记后在输出末尾提一句数量与路径；`-only` 模式也只加这一行。

**缺词候选**：词典里确实查不到的汉义（先按 §2 第 4 步穷尽同义字、上位词、复合、`--all`），另登记一条，给词典编委看，与 ✧ 词分开：

```
python "<SKILL_DIR>/scripts/nakthu_lex.py" gap --zh 霜 --refers "地上凝结的白色冰晶" --searched "霜 冰 凝" --handled "译者替换：雪凝（损失）" --source "《静夜思》"
```

写到同一目录的 `缺词候选.md`。无论后来配了复合、登记了 ✧ 还是被迫替换，都登记，`--handled` 如实写。`lookup` 查得到的词不要登记成缺词。

## 5 · 输出格式

详细模板与整段示例在 `references/output-formats.md`。要点：

**默认**：按节输出，每节一个代码块，三层对齐。

```
〔一〕
梦天语  <转写，一行一句，按原文行式>
逐字    <汉语逐词，复合用「—」，判据与附着用〔〕>
落点    <通顺汉语：梦天语真正指着的东西，不还原原文，不比梦天语多说一字>
```

原文有题就先给题：在第一节之前单列一块 `题  <梦天语题>`，逐字与落点同样给；题里有专名按「照义译」。原文是节、联、行的，行式照原文；逗号作分句界，句号作句界。

之后只加不超过五行的「译注」：关键的弯、最大的损失、新铸词数量。不写长篇解释。

**`-only`**：只给一个代码块，里面是梦天语译文，行式与原文对应，节间空一行；不加标题以外的任何文字（新铸词一行除外）。

**`-doc`**：写文件，章节为 引（可选）· 一 原文 · 二 梦天语译文 · 三 逐词直译 · 四 落点读 · 五 译解 · 六 增减与补注／三处译不过去的 · 七 临时词表 ✧ · 八 校记 · 结。译解里每一条论断都要能在档案里指到出处；不确定的写进校记，不写进译解。写完回报：文件路径、新铸词数、校验结果。

## 6 · 交稿前自查

- `check` 的 `✗` 清零；`△` 逐个核过；临时词在线内（≥ 40 词符占比 ≤ 5%，短文已登记 ≤ 3 枚）。
- 译注里引用的判据、词形，与译文里实际写的一致（逐个对一遍，别抄错）。
- 查不到的汉义都已 `gap` 登记，替换意象处都写进了损失清单。
- 座架有没有居于句首？否定有没有在判据之后？事化内部有没有挂判据？
- 有没有擅自加判据？有没有换了原文的意象？有没有写出「说不出」？
- 有没有给可排高下的词造了敬称？有没有借用汉语方位／数目／颜色？
- 落点读有没有比梦天语多说了一个字？译名在全篇是否一致？
- 新铸词是否已登记，且 `-doc` 的「临时词表」与列表文件一致？

## 7 · 诚实

不知道的就查，查不到的就标出来。校验脚本只核词形与一格一音节，**不能**证明语法正确；语法靠对照词法手册。遇到档案里互相矛盾处，以权威次序裁，并在校记里写明。三处以上「译者往前推」的句式，要逐条列进校记。

反向（梦天语 → 汉语）：同一套档案，按汇编第三部的三步译法——读出弯、认落点、在汉语里另找一条弯；判据译为话题化（〔亲眼〕等）。本 skill 不展开。
