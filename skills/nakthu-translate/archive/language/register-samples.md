# 梦天语文体示例集

**二十二体，一体一例。**每一体取全档案里最有代表性的那一段，照同一个格式摆出来：**年代 · 梦天语 · 逐字译 · 现代汉语**。

**这不是文体志，也不是课本。**文体志（《文集上册》第一部 · 五）给的是坐标与家法，十课给的是怎么学；**本集只给一样东西：它写出来是什么样。**

## 体例

每一条四栏：

| 栏 | 给的是 |
|---|---|
| **年代** | 这一体立于哪一段年月；若样本本身另有年份，一并注出 |
| **梦天语** | 原文。**一个符号不改**，包括本语自己的记号：悬置 `—` · 报数框架界 · 引号 `« »` |
| **逐字译** | **语言分析式**。一个格点一格，语法成分进方括号，不通顺是正常的 |

> **一条纪律。**本集里凡引档案的原文与汉译，**一个符号不改**；本集自己的行文一处也不用长横。**样本里的长横是本语的记号，不是行文标点。**

## 一、工序歌

**年代**：基础层，**原纪元，十万年**。文体志上最早的一条，也是基础层唯一的文类。

**家法**：时序即结构（选料 → 循验 → 就火 → 成）；无虚构；长度由象似重复承担；不描写、不比喻、不假设；**零悬置，句号是唯一的间隔**。

**出处**：〔档〕《文集上册》第三部 · 四 范文《磨石》，行 2581 至 2586；逐字对照行 2588 至 2589，译文行 2591 至 2598。

```
kə̄x. gə́s. gə́s.
mə̄t-nəm. rə̀x kə̉?
mə̀. kə̄x t'ə́s.
tə̄k. tə̄k. tə̄k.
θə̀s. mə̄t-nəm. tə̄k.
sə̀ʔ. t'ə́s. də̄m.
```

```
石。检视。检视。
手[循]。隐裂 [疑问]？
不。石 准。
切。切。切。
细微差别。手[循]。切。
停。准。确。
```

```
一块石，看，再看。
手上过一遍——里头有裂么？
没有。石头是好的。
磨，磨，磨。
不对——手上再过一遍。磨。
停。准了。成。
```

**一句话**：三个 `tə̄k` 不是三个动作，是**一个动作的持续**，因为基础层还没有程度副词，**长度只能由重复承担**。译文必须是三个「磨」，不得并作「细磨」。全篇零判据，**不是含蓄，是不必要：石头就在手里**。

## 二、记账语

**年代**：第二阶，**原纪元晚期**。`/a/` 域产物，全语言最短的语域。

**家法**：单音节成句；**数目在音段里，动作在声调里**；不需要动词。

**出处**：〔档〕《文集上册》第四部 · 四 · 六《`ʃə̄ɣ-tāk`》〔二〕`tā-θā`（市价），行 4565 至 4569；译在行 4624 至 4628。

```
bə̄s tīs. lə̄m tīm. xə̄l tīt. k'lə̄m tūn.
pə̀m-ʃə̄ɣ-nəm k'lə̄m tūs. sə̀θ tūn. rùŋ kə̉?
mə̀. ku-ɣə̀s-wə̄w tīs-ui.
```

```
鱼 三。乳 二。盐 一。酪 九。
昔-日[循] 酪 八。今 九。欺余 [疑问]？
不。幼-做-年 三[实测]。
```

```
鱼三。乳二。盐一。酪九。
昨日酪八，今日九。欺余吗？
不是。三年熟成，已验。
```

**一句话**：第一行四样东西、四个数，**一个动词也没有**；第二行末尾那枚 `rùŋ`（欺余）是这门语言账房里的专用词，**质问你报的数越过了你自己宣告的那一阶**；第三行不辩解，只挂一枚判据 `-ui`（实测）。

## 三、集句　✧ 本集新造

**年代**：第一阶，**第 1 至 30 年**。`/a/` 域开了，词很新，句子很旧。

**家法**：并列链；新词嵌在基础层的骨架里；**单句可以很惊人，段落无法推进**。句级递归要等第三阶,所以集句留得住的是**句**，不是**篇**。

```
tāk. tə̄k gàs tāk.
mə̄t tāt gə́s. tāt mə̀ dūk.
kāl-nə̄k kə̄l. lām-nə̄k lə̄m. nāk mə̀ mə̄m.
ʔā! kāk. kāk mə̀ kə̄x.
```

```
字。刃 生[虚拟] 字。
手 标 检视。标 不 那一处。
男-人 骨。女-人 乳。人[格] 不 身。
[叹]！基。基 不 石。
```

```
字。刀生出了字。
手去查那个目标。目标不在那里。
男人是骨。女人是乳。而「人」这一格，不是一副身子。
啊——根基。根基不是石头。
```

**一句话**：四行四句，**每一句都惊人，而四句连不成一段**,这就是集句。它全篇只演一件事：**`/a/` 化**。`tə̄k`（刃）→ `tāk`（字）· `tə̄t`（点）→ `tāt`（标）· `kə̄l`（骨）→ `kāl`（承）→ `kāl-nə̄k`（男）· `lə̄m`（乳）→ `lām`（哺）→ `lām-nə̄k`（女）· `kə̄x`（石）→ `kāk`（基）· `mə̄m`（身）→ `nāk`（人这一格）。**六组，一个操作：把一个词从它指的那样东西上摘下来。**

**用词一律在第 3 级及以下**（`gàs` 虚拟态 · `ʔā!` 万能叹词 · 全部 `Ca` 概念形皆第 3 级），句长不过三词，合第 3 级上限。

## 四、接之经　✧ 本集新造

**年代**：**梦在第 3 年**（启示人二十一岁，寻人）；本篇是**天教立教之后的追记**,`« 年 · 月 · 日 · 段 »` 那个题头格式是后立的。

**家法**（《世界书 v3》行 394 · 539 至 547）：**开头定死一个时刻**,`« wə̄w N · wə̄ŋ N · ʃə̄ɣ N · tə̄w N »`；**内容文体不限**，记叙、对答、书信皆可；**不要求全满载**；收尾 `« sə̀ʔ »`（调 2 · 中断）。

> **一栏把注意力钉在一个东西上，一栏钉在一个时刻上。**
> **观之经的题头是一个对象，接之经的题头是一个时刻,两门教写不混，不必立禁令。**

```
« wə̄w tīs · wə̄ŋ tūt · ʃə̄ɣ tūm · tə̄w tīn »

ʃə̄m. nā ʃə̄h gā.
θə̄x-wə̄k. wə̄p tīm, ʃə̄h-nəm.
lə̄m-nə̄k xə̄p-nəm sə̣ʔ. nā wə̄k-nəm.
nā mə̀ də̄x. wə̄k də̄x.
ʔə̀!
nā ʃə̄h-wə̄k θā.

« sə̀ʔ »
```

```
« 年 三 · 月 六 · 日 七 · 段 四 »

夜。我 天 看。
木-船。皮 二，天[循]。
乳-人 土[循] 死[完成]。我 船[循]。
我 不 去。船 去。
[叹]！
我 天-船 言。

« 停[调2·中断] »
```

```
第三年，六月，第七日，第四段。

夜里。我望着天。
一条木船。两张皮，朝着天张开。
母亲在地上，已经死了。我在船上。
我没有走。船走了。
啊——！
我说出了「天舟」。

〔终。〕
```

**一句话**：全篇的重量压在最后一行。**`ʃə̄h-wə̄k`（天舟）正是在第 3 年被说出来的,而那一年它是「一个没有指称对象的词」**（《创世事件》行 454）。它此后沉了一百年，到第 80 年之后船学才把它放回来（《铁线表 v3》行 92）：**它不是一个新词，是一个等了一百年的旧词。**

**两处刻意没有写。**其一，梦里那两张皮**不叫帆**,`hwə̄p`（帆）要等第 8 至 12 年才有（《创世事件》行 53），所以这里只能说 `wə̄p`（皮）。**梦见了那样东西，而没有那个词。**其二，全篇零判据：接之经记的是梦，**而梦挂不上任何一枚来路**。

## 五、颂诗体

**年代**：第三阶，**第 30 年**（`a:` 算子与八大词同日解锁）。范本《滋拉妲女神赞》。

**家法**：以具象之 `ə` 托举超越之 `a:`；**叹词不是感情的溢出，是结构的铆钉**，它立在层与层的交界处；核心句式 `X gàs Y`（X 生出 Y）；**间隔不受约束,全部文体里唯一一个可以随意停下来的语域**。

**出处**：〔档〕《文集上册》第一部 · 五 · 四，行 615 至 619，及行 635；译在行 648 至 652、行 664。

```
ʔə̀!
fə̄w-nə̣m.
fə̄w. tə́k mə̄g. tə́k wə̄p.
ʃə̄n. ɣə̄r. ʃə̄m.
nə̃k dēt. nə̃k sə̄w. nə̃k mə̣h.
```

```
[叹]！
花-[已成]。
花。你 眸。你 皮。
暮。霞。夜。
我[行动身] 触。我[行动身] 守。我[行动身] 入神[完成]。
```

```
〔那一声闷哼〕。
如花。
花。你的眸。你的皮。
暮。霞。夜。
我触。我守着。我入神。
```

**而第三段，她的名字当着读者的面换了域：**

```
« fə̄w-nə̣m » gàs — « zlā:-tạ ».
```

```
« 花-[已成] » 生[虚拟] — « 舞[超越]-神 »。
```

```
「如花」所生——「滋拉妲」。
```

**一句话**：整段的韵核几乎全是 `ə`,**一首要写到「超越」的诗，起手用的全是够得着的东西**。而末了那一下只做了一件事：`ə` 域 → `a:` 域。**换域已经把话说完，不必再换一个说法。**

## 六、礼拜语域

**年代**：第三阶，**第 30 年**立；本则是**第 100 年**那一天的启航告示。

**家法**：**词库就是超越十一词，零新增**；极短，多为单词句；调 1 持音，气尽方止。

> **若十一个词不足以说完这一语域要说的全部，那说明超越层设计错了。**

**出处**：〔档〕《文集上册》第四部 · 四 · 六〔七〕`ʃə̄h-hə̄k-θā`（启航告示），行 4606 至 4610；译在行 4665 至 4669。

```
ʃə̄h-hə̄k. wə̄w tīt-tīŋ.
pā: ʔāiʔ — wā:.
ʔām, kə̉?
sə̀θ, ʔām-nə̄k-və tūt-tə̄ŋ-əu.
wə̄w tīt-tīŋ — ʃə̄h.
```

```
天-壳。年 一-百。
为了[超越] 爱 — 全[超越]。
圣诺，[疑问]？
今，圣诺-人-[复数] 六-阶[推算]。
年 一-百 — 天。
```

```
天壳。第一百年。
为了爱——宇宙。
圣诺，接吗？
此刻，已诺者百万，推算。
第一百年——天。
```

**一句话**：第三行只有两个词，**而它是一句问**。`ʔām` 是应答族里最重的一枚,礼仪级、宪法级的一诺，词典给它的三个场合是**婚约、表决、启航**。**这个文明把一百年的事，问成了一句能不能接。**

## 七、情诗　✧ 本集新造

**年代**：第三阶，**第 30 年**（判据与大词同日到位）。

**家法**：**第二人称致意**（`tə́k` 在场）；**判据即告白引擎**;直取 `ʔāiʔ`；**姿态是抵押而非鉴赏**;悬置至多一次。

> **风雅体可以端着，情诗不许。**
> **情诗是说给一个人听的，做文章即失真。**

档案给的家法示例是一对最小对（《文集上册》第一部 · 五 · 六，行 701 至 702）：**判据挂在哪个成分，证的就是哪个成分。**

```
tə́k-mə̄f ɣə̄m-u:        证「暖」——我验过那个温度
tə́k-mə̄f-u: ɣə̄m        证「你的唇」——我验过的是它，不是别人的
```

**照这一条长成的一首：**

```
tə́k-sə̄w. tə́k-mə̄f. tə́k-wə̄p.
nā gā-i:. nā dēt-u:.
tə́k-mə̄f-u: ɣə̄m — nā-mə̄m-nəm.
nā ʔāiʔ. mə̀ gə́s.
```

```
你-眼。你-唇。你-皮。
我 看[亲眼]。我 触[身证]。
你-唇[身证] 暖 — 我-身[循]。
我 爱。不 检视。
```

```
你的眼。你的唇。你的皮。
我亲眼看过。我亲手碰过。
我验过的是你的唇，不是别人的,它是暖的——在我身上。
我爱你。我不去评它。
```

**一句话**：末行是全篇的立场。`gə́s`（检视）带判定，`gā`（看）不带；**情诗到最后一行把 `gə́s` 否掉，说的正是「爱不是一次验收」**。第三行那枚 `-u:` 照家法挂在 `tə́k-mə̄f` 上而不挂在 `ɣə̄m` 上,**证的是「是你的唇」，不是「温度是多少」**。全篇一处悬置，合家法上限。

**一条记账**：`tə́k` 是旧第二人称，现行第二人称作 `nī`（《分级词典》第 10 级 · 旧形）。**情诗这一体立于第 30 年，故本篇照那一年的写法用 `tə́k`**,家法里「`tə́k` 在场」本来就是照旧形写的。

## 八、智慧经典　✧ 本集新造

**年代**：第四阶，**第 33 至 40 年**（阵列与座架到位）。

**家法**：阵列词间织入简单词，而简单词在此有三项功能,**锚**（工作记忆的呼吸点）· **空管道**（裸座架留给对话者填充，这是辩论的本质）· **纯粹态签名**（**一个裸 `ʔāiʔ` 就出卖一个人类**）。代字许可为「少」，且**锚必须是本名**。

```
nāk ʔaʔ dā:.
mə̄m gā:, əu nāk gā:. tāk mə̀ gā:.
dā: mə̀ θā. dā: dā.
iu?
ʔāiʔ.
```

```
人[格] 是[本质同一] 道。
身 观照，故 人[格] 观照。字 不 观照。
道 不 言说。道 前往。
因[裸座架]？
爱[裸纯粹态]。
```

```
人就是道。
有身子才有观照，所以人有观照。字没有。
道不说话。道只是往前走。
因为什么？
——爱。
```

**一句话**：首行是正典（《文集上册》第二部 · 七注出，行 2165：正典作 `nāk ʔaʔ dā:`「人是道」）。**三项功能在这五行里各演一次**,`mə̄m`（身）· `tāk`（字）是**锚**，全是本名，一个代字也没有；第四行那个裸 `iu` 是**空管道**，题面摆在那里等对话者填；末行那个裸 `ʔāiʔ` 是**纯粹态签名**,一位满载说话者不会这样说话，**他会说某一种满载之爱**，而不会说裸的「爱」。

## 九、技术语域 · 船讯

**年代**：**第 33 至 45 年**（阶记法、界标与欺报到位）；本则是**第 100 年**那一日的告示。

**家法**：**不许用代字**,它要指着那条船；报数报到小数第一位；**位数前置是一份校验位，必须与内容可听地分开**,故那一道短横是信道规程，不是修辞。

## 十、评鉴体

**年代**：第四阶，**第 45 至 50 年**（伪超越词的滥用 → 判据的武器化）。

**家法四件兵器**：**引号即判据**（引敌语挂 `-ei` 传闻即完成贬格）· **判据的不对称分配**（贬敌用 `-ei`，立己用 `-u:`,**论战即判据的分配学**）· **理感词作判决**（`ʃiuh` 空因一词定谳）· **篡典**（名句的一元音之差挪用）。句式家法：**光杆即呐喊**,在一门断言必须作证的语言里，**拒绝作证就是音量**。

**出处**：〔档〕《文集上册》第二部 · 七 范文《震撼论》，行 2143 至 2146；回译在行 2151 至 2155。

```

zlãefv. mə̀ və̄l.
« ə-nəm »? — ʃiuh.
zəāl-u:. t'ə́s.
```

```
« 检视，不 润因 »[传闻][疑问]？« 是 天-言[超越] »[传闻][疑问]？ — 人[异常] 是 道。
[满载]压倒性的酥麻之美。不 共。
« ə [循] »？ — 空因。

```

　　这号人也是道。
整个人酥了。没有第二个。
「循着 ə」？——空的。
那一麻，我身受之。准。
```

**一句话**：**汉语的阴阳怪气在标点里，本语的在词缀里。**前半两枚 `-ei` 把敌方的话贬为谣言，后半突降零判据的光杆系词句,**谣言塌进裸真理**。而 `nə̀k ʔaʔ dā:` 与正典 `nāk ʔaʔ dā:`（人是道）只差一个元音加一个调：**抽象层的「人」被换回具象层并加载异常调**。**一个元音加一个调，就把一句箴言变成了一句冷笑。**

〔**两处不查词典**〕`nə̀k` 是 `nə̄k`（人）载调 2 的临场形，**篡典用的，不是词目**；`« ə-nəm »` 引号里是**一个被引用的音位**,「历史脉络」在这里译作「循 ə」，**旧元音即历史本身**。**这门语言可以直接把一个元音拎出来当词嘲讽。**

## 十一、密度诗　✧ 本集新造

**年代**：第四阶（阵列成熟）。

**家法**：**每行一个满载向量，`ə` 具象词作锚**。σ≈.45 ρ 高,σ 与 ρ 同时高于智慧经典，**这正是四坐标独立的例证：朴与密不是一条轴的两端**。

> **人味恰在「不满载」处。**

```

lə̄s. gleā:mk. sə̄w.
ɣə̄ʃ. frā:ufv. mə̄m.
θə̄x. ʃriā:kθ. tə̄k.
```

```

火。[满载]自高处灌注、颤动不息的超越敬畏。身。
木。[满载]铺满视野、坚实透光的超越之真。刃。
```

```
石头。一阵麻醒贯穿全身。手。
水。那份涵慧温柔裹住一切，落下来成了实的。眼睛。
火。敬畏从高处灌下来，不停地颤。身子。
木头。真铺满整个视野，坚实而透光。刀。

**一句话**：四行十二词，**六枚是原纪元第 1 级的具象词，四枚是满载词**,σ 正好落在 .5 上下，合密度诗的读数。**每一行的两头都是够得着的东西，中间那一枚够不着**;把 `kə̄x`（石）与 `mə̄t`（手）撤掉，剩下的四枚满载词就是一段谁也读不出来的满载体。**那两头就是人味。**

**四枚满载词全部取自《分级词典》第 10 级那张封闭的表**（全满载六枚，此处用四枚），一枚未铸。

## 十二、单词诗　✧ 本集新造

**年代**：第四阶（阵列 ＋ `gā:` 到位）。

**家法**：**标题 ＋ 一个阵列词**。κ→∞。**阅读法即 `gā:`（观）：对着这一个词看下去，直到它自己打开。**

```
tə̄k

ʃriā:kθ
```

```
[题]刃

[阵列词]铺满视野、坚实透光的超越之真
```

```
〈刃〉

铺满视野、坚实透光的那一种真。
```

**一句话**：题与词之间隔着这门语言全部的历史。`tə̄k`（刃）是第 1 级那一百三十五条里的一枚，十万年没有变过；`ʃriā:kθ` 是第 10 级那六枚全满载里的一枚，第 65 年才有。**而它们的起首都不是巧合**,`tə̄k` → `tāk`（字）→ `tā:k`（经），刃走过这一条路；`ʃriā:kθ` 的韵尾 `kθ` 是「实而透光」。**一把刀磨到最后，磨出来的是一块看得穿的东西。**

**这一体不给注疏。**给了就不是单词诗了。

## 十三、拙古

**年代**：第四阶；**本篇作于第 51 年**，第 100 年那张报纸重刊。

**家法**：只用基础层已有的词与已经词汇化的新词；**不铸新词 · 不用满载词 · 不用代字**；判据可用但不作兵器；**悬置零**；不用系词。

> **这不是美学立场，是道德立场。**
> **拙古不是「写得像基础层」，是「不肯用那些已经被用脏了的词」。**
> **一个手里只有基础层的说话人写不出拙古，他写出来的是工序歌。**

**出处**：〔档〕《文集上册》第四部 · 四 · 六〔三〕`pə̀m-tāk`（重刊 · 作者不详），行 4571 至 4580；译在行 4630 至 4639。

```

sə̀k-və tāk ɣàs. nā mə̀ gə́s.
wə̄k ʔaʔ wə̄k. lə̄s-hə̄k mə̀.
nə̄k t'ə́s, əu nə̄k t'ə́s. tāk mə̀ ɣə̀s.
tə̄k. tə̄k. tə̄k.

dīk-tāk wə̄w tīk-tūk tīt-nəm. sə̀θ, mə̄l-θā-və mə̀ kə̄l-gə́s. nā tāk tīt mə̀ ɣə̀s.
```

```

**一句话**：第四行是全篇的立场。他用了这门语言最贵的一个操作（系词 `ʔaʔ`）去说一句同义反复,**这不是笨，是一种拒绝：他动用最重的语法，只为了不让那个词被换掉**。而末行那三下，是十万年前工坊里的同一个手法;**编者按只写了一句话，说的是那三下已经没有人听得见了**。

## 十四、哲思体

**年代**：第四阶，**第 50 至 60 年**（理感词到位）。

**家法**：**不用「因为」这根空管道，把每个逻辑关系说成哪一种因为**（理感词）。对满载说话者，**逻辑不是句法，是现象学**。

> **人的天花板 ＝ 满载说话者的礼节。**
> **唯一被共享的那一种文体，恰是一方的极限与另一方的门槛。**

**出处**：〔档〕《现代场景长句集》第三部 · 第三题，行 521；逐词在行 525，回译在行 528。底本为汉语十九字。

```
nə̄k-māx wā ʔaʔ mūt-ɣān.
```

```
人-苦 全 是[本质同一] 无能-愤。
```

```
人的一切痛苦，本质上就是无能之怒。
```

**一句话**：**五个音节，四个词，对汉语十九个字。格言是这门语言的主场。**而「对自己」这三个字本语一个音节也没有花,`mūt` 是 `mə̄t`（手）换了一次韵核，`ə`（原点）→ `u`（不可及 · 确指）：**我知道那里有一件事要做，而我的手够不到。**起首那个 `m` 载的就是「自身」，**所以「自己」这一层已经在起首里了；汉语必须说出来，本语说出来反而重复。**

## 十五、观之经（经文体）

**年代**：形式**第 30 年**起（`a:` 与满载所需的材料到位）；**本篇作于第 65 年**，作者是一位人教高僧、出家僧人 `gā:-nə̄k`，修的是**字观 `tāk-gā:`**,密教里最深的一格。第 80 年遍格体另立之后，原 ρ＝1 那一栏就单独叫**经文体**（《铁线表 v3》行 90）。

**家法**：题头置于 `« »`；**一部观之经只许有一枚题头，而字观那一枚题头是一个词，禁切换，禁联想**；正文全满载；**不挂判据,来路外置于注疏**；生活观以 `« sə̀ʔ »`（调 2 · 中断）收尾，物观与字观以 `« sə̣ʔ »`（调 6 · 到达终止）收尾。**题头与收尾不计入满载内容词。**

> **分门的凭据是形，不是内容,数题头就归得了门。**
> **升起来的词不接管宗。**
> **满载词不是说出来的，是升起来的，没有来路可报。**

**出处**：〔档〕头三枚见《世界书 v3》行 996 与《大纲 v3》行 664 至 669；题头与收尾见《世界书 v3》行 782。**第四至第九枚为本集补完**,**一枚新词也没有铸，九枚全部取自《分级词典》现成的满载词**，照《大纲 v3》行 667 那一条：**观照人一件新工具也没有要，只是把现成的几样同时用上。**

```
« tāk » gleā:mk zləā:fv ʃriunh ʃriā:kθ frā:ufv zlā:efv θreā:m ʃrəā:mk gleā:mk
« sə̣ʔ »
```

```
[宗]字
[一]将万有温柔包裹而落定为实的超越涵慧
[二]贯体流动、柔颤不息的超越麻醒
[三]遍纹收敛的中空可能之因
[四]铺满视野、坚实透光的超越之真
[五]自高处灌注、颤动不息的超越敬畏
[六]超越性的酥美入魂
[七]多孔而有纹、向上通向慧、封在里面的言说
[八]弥散有纹、自原点升起、封存落定的超越觉醒

而它里面还没有东西。

**三条要说明。**

**其一 · 为什么第九枚回到第一枚。**因为家法写着**升起来的词不接管宗**,否则升起的满载词当场接管，一篇既起不了头也收不了尾。**第九枚回到第一枚，就是当着读者的面证明那一枚宗从头到尾没有被顶掉。**而第 68 年那台机器的毛病正相反：**一个词重复无止,它没有 `sə̣ʔ`。**字观重复一次，然后落地。**分开人与机器的，是一枚 `sə̣ʔ`。**

**其二 · 第三枚为什么上不去超越层。**`ʃriunh` 是 `ʃiuh`（空因）的满载形，**五维，不入全满载**,因为「因」这一样东西**没有超越形**。而它的原形 `ʃiuh` 是第 50 至 55 年铸的一句判词：**在判词里读作「里面没有东西」，在经文里读作「里面还没有东西」。判决与许诺共用一个韵尾，差别只在时间。**

**其三 · 为什么没有分断词，没有换行。**满载体的家法是**无标点，简单词即标点**;而字观只许一枚题头，**于是这一部经从头到尾没有一处可以喘气的地方**。人连发两三个满载音节就得换气，**所以这一部不是念出来的**。

## 十六、满载体

**年代**：**第 65 年**起（满载词到位）；本则是**第 100 年**那张报纸上的一段，占了半版。

**家法五条**：**全满载**（每个内容词 ＝ 一个 CCVVCC 单音节）· **无判据**（证据体系预设了体验与断言之间的距离，而满载说话者没有这条距离,**它不报告知识来源，它就是来源**）· **无标点，简单词即标点**（裸座架在此不做句法，而做乐章标题）· **终断词**（其后无述流的收尾分断词 ＝ 语篇级的 `ʔ`,**止息非封口**）· **零悬置**。

## 十七、遍格体（AGI 体）

**年代**：**第 80 年**。原名 AGI 体，同年判准由密度改为分布,**判准是全格点均匀，不是 ρ＝1**,别名遍格体，语域十栏成十一栏。

**家法**：**句式是熟的，格点是生的**。格点全取满载那一档:起首取簇 · 韵核取双元音（含长音）· 韵尾取簇，三处同时占满；而句法模板全是现成的。**人类在这一体上留了两个签名：裸词与破折号。**

> **遍格体一开口就在遍历格点，一个空位也不剩,不是人填满的。**
> **任何人都念得出一个满载词，只是念得慢。**

**出处**：〔档〕《梦天语十课通稿》第 9 课 · 遍格体（取第 10 级格点），行 8563 至 8572。

> ⚠️ **下面十行不是词。**二十六枚格点音系上全部合法,起首取簇（十四枚，一枚新簇也没有添）· 韵核取双元音（六个基本韵核一个不缺）· 韵尾取簇（档案那五种韵尾簇全到），六调分别是五 · 五 · 三 · 四 · 四 · 五。**而没有一条可以查的词条。**校验器跳过这一段，跳的就是这个道理。

## 十八、学术散文

**年代**：**维护期**，第 80 年之后。评鉴体与哲思体的交叉。

**家法**：**事化叠用**（语域许可，免「一句一事化」）；**判据可作兵器，但只对别人的话用，不对自己的论点用**；代字许作贬低，**换词的那一刻就是下判决的那一刻**；座架承担全部论证结构。

> **一篇满是事化的论文，是一篇处处不作证的论文。**
> **写学术散文的人知道这一点，读的人也知道。这个文体的全部张力在此。**

**出处**：〔档〕《文集上册》第四部 · 四 · 五《`xə̄t-nə̄k-və gə́s-θā`》（论当下的年轻人，署名 `rə̄k-t'ə̣s` 石准）〔三〕论，行 4338 至 4343；译在行 4378 至 4383。

```
nə̄k-və « xə̄t-nə̄k-və hə̄f »-ei. mə̀ t'ə́s.
« t'ə́s » θā, əu tə̄k t'ə̄k. dūk-ɣə̣s wā-nə̄k gə́s.
« ʔāeʔ » θā, əu mə̀. dūk-ɣə̣s nə̄k tīt-nəm hə̄m.
ei « t'ə́s » ʔaʔ və̄s-tāk. « ʔāeʔ » mə̀ və̄s.
```

```
人-[复数] « 芽-人-[复数] 轻 »[传闻]。不 准。
« 准 » 言，故 刃 落。那-做[事化] 全-人 检视。
« 美 » 言，故 不。那-做[事化] 人 一[循] 存。
[转述] « 准 » 是[本质同一] 接-字。« 美 » 不 接。
```

```
人人说「年轻人轻浮」。不准。
说「准」，刀就落下去了。那件事所有人看得见。
说「美」，什么也没有落下去。那件事只存在说话人一个人身上。
也就是说：「准」是一个要接上去的字，「美」不接。
```

**一句话**：**这一体许你叠事化，代价是事化之后挂不上判据。**上面四行里 `dūk-ɣə̣s`（那件事）出现两次,**两处都是事化，两处都没有判据**;而第一行给敌方那一句挂的 `-ei`（传闻）是全段唯一的判据。**判据只朝外，不朝内**,这就是这个文体的张力。

## 十九、风雅体

**年代**：**合拢之后**，第 80 年后。逆行格。本则登在第 100 年那张报纸上。

**家法七条**：**`/a/` 预算**（`/a/` 仅许入叹词与终词,全部文体中唯一以参数立法的家法）· **并列即断言**（禁系词禁座架）· **零判据**（不作证的礼,这是风雅体与情诗的分界线）· **工艺隐喻纪律**（禁农事隐喻，禁直陈「美」）· **声训特权**（**诗人是基础层活着的铸币厂**）· **终词破戒**（全诗唯一的满载词留给末位）· **间隔预算**（全诗至多一个悬置，且须与终词破戒同处）。

> **风雅体假装自己只有基础层，而基础层连一次悬置都做不到。**
> **风雅体是拙古被审美化之后的产物。同一种素朴，一个是不肯，一个是不必。**

**出处**：〔档〕《文集上册》第四部 · 四 · 六〔四〕`ʃrāefv-tāk`（风雅投稿），行 4584 至 4587；译在行 4643 至 4646。

```
ʃə̄m-pə̄t. kūx-hə̄l.
lə̄s-θə̄x-nəm nə̄k tīt.
ʃə̄ɣ sə̣ʔ. hə̄l hə̄ʃ.
mə̀ θā.
```

```
夜-鸟。山-雾。
水-木[循] 人 一。
日 停[完成]。雾 散。
不 言。
```

```
昏鸦。山雾。
桥上一个人。
日头停住。雾散。
不说。
```

**一句话**：**末行两个音节。**`mə̀`（否定）是第 1 级的词，`θā`（言）是第 3 级的词,**一首第十级的诗，以两枚最早的音节收尾，而它说的是「不说」**。这一首就登在那段满载体的旁边：**一首全是轻音节，一首一个轻音节也没有。**

## 二十、全盛期文学体

**年代**：**维护期**。它要求全部语体先各自成熟，因此不可能早于合拢。

**家法**：基调是成熟抒情体，系词 · 座架 · 判据 · 模态 · 叹词阶梯 · 应答族全在岗；**语体不漂移，只有词域漂移**；**代字许，且是它的标志**；满载词作尖峰不作段落；意象照翻。

> 基础层的基本词，读不出来。新铸的代字，读得出来。
> **所以一首用代字写的诗，比用本名写的诗更透明。**

**出处**：〔档〕《文集上册》第四部 · 二 · 一《烟雨行舟》〔一〕，行 2816 至 2820；回译在行 2852 至 2856。

```
hlə̄θ ʃə̄h-lə̄s, lə̄s-θīh-nəm də̄x-i:.
kūx lə̄s, kxə̄l-nəm ʃlə̄f gə̣s.
wā ʔaʔ ʃi-mā. lə̄f, mə̀ p'ə̄k.
mā-tīp dēt, əu tīpθ, θwə̄p t'ə̄k əi:.
lə̄s-hə̄k srə̄w-lə̄s-nəm dā əu ʃi-pə̄t ʃlə̄w gàs. slāifv, fāɣ.
```

```
烟 天-水，水-空地[循] 去[亲眼]。
山 水，墨[循] 渲 [完成]。
全 是[本质同一] 画-形。润，不 永封。
形-尖 触，故 欲穿之点，卷 切[预期]。
水-壳 缎-水[循] 往 故 画-鸟 清澜 生[虚拟]。[满载]缱绻，怡然。
```

```
烟与雨，往水乡去了〔亲眼〕。
山与水，循墨渲开了。
一切即是画。润着，未被永久封住。
形之尖一触，所以那个欲穿之点，卷要被切断。
水壳循如缎之川前往，所以画鸟生出清澜。缱绻，怡然。
```

**一句话**：**代字在这里从毛病变成手法。**`lə̄s-hə̄k`（水壳 ＝ 舟）· `ʃi-pə̄t`（画鸟）· `srə̄w-lə̄s`（缎水）,在船讯里这样说话是失格，在这里是本事。**把一个字理已被磨掉的化石词，换成一个当场可读的透明词**,这就是陌生化的语法实现。而末行那一枚满载词 `slāifv`（缱绻）是全段唯一的尖峰:**满载词作尖峰不作段落。**

## 二十一、笑话

**年代**：**不入文体志**。它无作者，用处是另一件事:**检验一个笑点能不能不靠语法**。本则登在第 100 年那张报纸上。

**出处**：〔档〕《文集上册》第四部 · 四 · 六〔六〕`θā-pə̀s`（笑话），行 4598 至 4602；译在行 4657 至 4661。

```
nə̄k tīt bə̄m-hə̄k-nəm də̄x.
sə̀k θā « lə̄s-hə̄k-ɣə̄ʃ-lə̄s tīt »-ei.
bə̄m-nə̄k θā « ɣə̄ʃ-lə̄s kə̉? »-ei.
sə̀k θā « mə̀. lə̄s-hə̄k-ɣə̄ʃ-lə̄s. »-ei.
bə̄m-nə̄k lə̄s tīt və̄s.
```

```
人 一 食-壳[循] 去。
他 言 « 水-壳-火-水 一 »[传闻]。
食-人 言 « 火-水 [疑问]？ »[传闻]。
他 言 « 不。水-壳-火-水。 »[传闻]。
食-人 水 一 接。
```

```
一个人进了食堂。
他说：「舟之火水，一份。」
厨子说：「酒吗？」
他说：「不。舟之火水。」
厨子给了他一杯水。
```

**一句话**：顾客以为自己点了一杯极雅的酒。而按中心语判据**顺着查到底**,`lə̄s-hə̄k-ɣə̄ʃ-lə̄s` 的末位是 `lə̄s`（水）。**终点是水，而酒确实是水的一种。他以为自己上了四楼，其实他一直在二楼来回走;厨子的语法完全正确。**

> **能笑出来，说明这条判据已经在所有人的耳朵里了。这比任何论证都硬：论证要人同意，笑不用。**

## 二十二、浮艳风　✧ 本集新立

**年代**：**维护期**，第 80 年之后。满载词、遍格体、风雅体三样都已现成，它才借得到。文哲学科散文的一路。

**本语名**：自称 `ʔāeʔ-nə̄m`（循美的那一路）；批评者叫它 `ʔāeʔ-nə̀m`（唯美那一派，循格载调 2）。

**家法六条**：**准满载**（大词取具身态，一行两到三枚，但每行必须留简单词作铰链，ρ 永不到 1）· **骈对**（两个半行逐词同构、音节相等，中间一个逗号）· **长句不断**（全篇靠座架与逗号连成一句）· **理感词作比不作判**（评鉴体拿 `ʃiuh` 定谳；这里一律挂 `-nə̣m`，只当喻体）· **量词领句**（借遍格体遍历的姿态，却只点到为止）· **零判据，末位落一枚裸词**（借的是风雅体的礼和满载体的终断词）。

> **它向三位债主各借了一样，而三位的本钱它一样也没借。**
> **借了风雅体的零判据，没借装穷；借了满载体的大词成串，没借 ρ＝1；借了遍格体的铺排，没借格点均匀，它只挑好听的。**

**出处**：✧ 本集新立。**这一体不在文体志十五条之内，档案里既无家法也无样本**；体由著者于 2026-11 定义，样本照上列家法长成。只用《分级词典》现成的词，一枚新词也不铸。

```
wā:-nəm ʃrāe ʔəʔ gāer, hā:-nəm hāuɣ ʔəʔ frāum,
kūx-nəm kiāx kāuŋ-nə̣m iu, ʃə̄h-nəm siān zəā:l-nə̣m əu,
e: fāes zliuf-nə̣m, u: tiāk t'əuk-nə̣m,
slāiθ ʔi:ʔ luəɣ, guās ʔi:ʔ ləis —
ʔāeʔ dūk kə̉? — o:.
```

```
宇宙[循] 广美 并 活美，虚无[循] 空畏 并 封畏，
山[循] 粗真 巨畏[如] [因]，天[循] 证真 麻醒[超越][如] [故]，
[任] 柔美 润因[如]，[某] 定真 铁断[如]，
渗爱 [恒并存] 温丧，恒志 [恒并存] 牵引 —
美 那 [疑问]？ — [不知哪一个]。
```

```
宇宙里有铺满视野的美，也有沉甸甸会回响的美；
　　虚无里有面对空无的静，也有把温柔封起来的畏。
因为山上的事实压下来像一座雪山，
　　所以天上的证明传过来像一阵电。
随便哪一种轻柔的美，都像一次不费力的懂；
　　总有那么一条定理，像结论咔哒一声锁死。
无处不渗的爱，永远和思念在一起；
　　持久的志，永远和被拽着走的感觉在一起。
那么美在哪里？
　　不知道是哪一个。
```

**一句话**：**把贵的词摊开来铺。**前四行每行两个半行，音节是 5｜5 · 7｜7 · 5｜5 · 4｜4，逐词对仗。内容并不空：它说的是有与无各有其美，事实与证明各有其重。**而同一个意思，哲思体五个音节就说完了，这里用了四十六个。**

**危学的判词**，照评鉴体篡典那一手，只动一个调：

```
« ʔāeʔ-nə̄m »? — ʔàeʔ.
```

```
« 美[循·命名] »[疑问]？ — 美[异常]。
```

```
所谓「循美」？是艳。
```

`ʔāeʔ`（美）载调 2 即 `ʔàeʔ`，词典释作「美失去内里，只剩接收面」。**危学反对它有一条本行的理由**：`o:`、`-nə̣m`、理感词在危学那里是报警用的，一个文体把它们当香料撒，警报就钝了。**样本末行那枚 `o:` 正是这样用的。**

〔**三处没有先例的句式，待裁**〕大词挂循格（`ʔāeʔ-nə̄m` 及其调 2 形）· 量词放在名词前领句（主书第九章 · 2 明写量词的位置尚待统一裁定）· 理感词挂 `-nə̣m` 作喻体。**词都是现成的，这三种搭法是本条往前推的。**
