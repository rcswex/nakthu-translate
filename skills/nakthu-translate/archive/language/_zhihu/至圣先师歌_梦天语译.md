# 丘成桐《至圣先师歌》译入梦天语（Nakthu 语）

---

## 一 · 原文

《至圣先师歌》　丘成桐

```
尼丘孕灵兮，横流启圣；
洙泗风传兮，大道始正。
忠恕仁爱兮，君臣父子；
允执厥中兮，至善始止。

传习六艺兮，固守五伦；
行遵礼乐兮，泛爱仁人。
春秋断恶兮，易测玄机；
存亡继绝兮，东西可依。

夫子高山兮，百代嘉名；
后学轨范兮，万世太平。
儒道昭远兮，华夏纪纲；
绳墨规矩兮，求真不忘！
```

## 四 · 汉语回译

把梦天语这一篇真正说出的东西，用汉语再说一遍。不还原成原歌词，也不比梦天语多说一个字。

```
〔一〕
听说，土山生出了一份灵性，啊——
无岸的水里，有一位老师。
两条水之间，风把它传开，啊——
道，从此准了。
担得起。容得下。抱得住。爱。啊——
定事的人与做活的人相接；父亲与孩子相接。
手里确实握着两端之间的那一处，啊——
未准，不许停。

〔二〕
六门手艺，传开，啊——
人的五条路，守着不放。
照那式样做。照那和鸣做。啊——
众人当中有一种爱，无处不渗。
《春秋》把那本来如此的恶一刀切断，啊——
《变通》穿过去，量那一团够不着也认不出的东西。
停住的，封存起来；断绝的，接回去。啊——
日出的那一处，日落的那一处，都可以拿它垫底。

〔三〕
教人的那个人停住了，啊——
而那不终止的言，没有停。
老师已是山了：够不着，而确在那里。啊——
一百代人，他自己的名字，一直是准的。
后来的人，照老师做，啊——
一万代人不坏：那兆头会一直指着。
老师的道，传到够不着的地方，啊——
在花夏，它是承重的那副架子。
线。墨。准。啊——
求——真，不至于再也认不出！
```

## 五 · 译笔

### 5.1 「圣」在一个长音里

梦天语不排高下，这是它唯一的永久禁列。初读之下，「至圣」似乎无处可放：它像是把一个人放到所有人之上。

**但这门语言里的「敬」本来就不是「上」。**敬称的造法只有一条：把词根的元音拉长。而长音加的只有一样东西，**不终止**。

```
θā-nə̄k     教者：说话的那个人
θā:-nə̄k    老师（敬称）：言，不终止
```

`θā` 是言，`θā:` 是语（言说本身，不落在哪一句上）。**「师」与「圣」之间，只差一个长音符。**圣不是比别人高的那个师，是他的言没有终止的那个师。

这一层在词里本来就有，只是藏着。译文在第三节开头**增一联**，把它念出声：

```
θā-nə̄k sə̣ʔ ʔā:!       教人的那个人停住了，
θā: sə̀ʔ mə̀.            而那不终止的言，没有停。
```

前一行用短音的 `θā-nə̄k`，全篇只此一处不用敬称：停住的是一副身子。后一行只剩 `θā:`，连「人」也去掉了。**两行之间丢掉的是 `nə̄k`，多出的是 `:`。**

这一联之后，下文三处 `θā:-nə̄k` 才有了分量：读者已经知道那个长音是什么。**「至圣」的「至」，就译在这个长音上：不是最高，是不止。**

### 5.2 「高」是够不着

「夫子高山」的「高」，同样不必译成「在上」。

```
θā:-nə̄k kūx-nə̣m, kāuŋ.
```

`kūx-nə̣m`：循格调 6，「已经是山那样了」。`kāuŋ`【畏】：巨畏，面对雪山、星空一类巨大而够不到者。它的韵核是 `āu`，落点在 `u`：**确知其在，够不着**。

《论语》里说的本来也是这个：「仰之弥高，钻之弥坚。」颜渊说的不是夫子的位置，是自己够不着。**梦天语的「高」是一个关于可及性的元音，不是一个关于位次的词。**

`kāuŋ` 是译文增的一个词。「高山」二字，`kūx` 接住了山，`kāuŋ` 接住了高。

### 5.3 「君臣父子」：四个人，两条线

```
t'ə́s-nə̄k tə̄k-ɣə̀s-nə̄k və̄s. kə̄l-nə̄k ku-nə̄k və̄s.
```

**君臣**译作 `t'ə́s-nə̄k`（定事人：判定一件东西准不准的那个人）与 `tə̄k-ɣə̀s-nə̄k`（做物人）。两枚都是这个文明自己的职分名，词典明写「常规标签本身不编码等级」。孔子答齐景公「君君，臣臣」，说的是各尽其分；**分，梦天语说得出，而且说得很实：一个人定，一个人做。**

**父子**译作 `kə̄l-nə̄k`（骨-人：那一副架子从他那里来）与 `ku-nə̄k`（孩子）。

两对之间用的是同一个谓词 `və̄s`（接：把两样接上）。原文四个名词并排，关系留在字外；译文把关系说了出来，而且两对用的是同一个字。**读下来是：定事的与做活的之间有一条线，父亲与孩子之间有一条线，而这是同一种线。**

这一行紧跟在「忠恕仁爱」之后。四德是线上流的东西，这一行是线本身。

### 5.4 「兮」

原文十二个「兮」。它不载义，是一口气。

梦天语有一枚正合的叹词：`ʔā:!`，词典释义「纯粹开放之叹，无方向，一口气吐到尽」。译文每一处都留着，加上增的一联，共十三处。

颂诗体的家法说，叹词不是感情的溢出，是结构的铆钉。骚体的「兮」做的是同一件事。**两种诗体在同一个位置钉了同一种钉子。**

### 5.5 语气落在槽里

原文全篇是直陈句，语气靠虚字带出：始、可、不忘，和末尾那个叹号。梦天语把它们分到了不同的槽里，每一处都有形可指。

| 原文 | 梦天语的手段 | 所在 |
|---|---|---|
| 孕灵（传说） | 判据 `-ei` 转述 | 一 · 1 |
| 始正（从此正了） | 调 6 完成 `t'ə̣s` | 一 · 4 |
| 始止（到了才停） | 蕴含 `ʔuʔ` ＋ 禁 `mà` | 一 · 8 |
| 行遵（照着做） | 循格调 3 `-nə́m` | 二 · 3 |
| 继绝（把断的接上） | 调 3 执行 `və́s` | 二 · 7 |
| 可依 | 模态 `əi:` 可 | 二 · 8 |
| 高山（已经是了） | 循格调 6 `-nə̣m` | 三 · 3 |
| 轨范（后人照他做） | 循格调 3 `-nə́m` | 三 · 5 |
| 太平（愿如此） | 模态 `io:` 终将 | 三 · 6 |
| 不忘 | 模态 `uo:` ＋ 否定 | 三 · 10 |

**三处是这一篇的眼。**

**其一 · 首行的 `-ei`。**尼丘孕灵是传说，说话人不在场。梦天语在第一行就交代：这是听来的。此后各行不再挂判据，那是颂诗的本色，颂者不为颂扬作证。**一首颂歌的第一个动作是承认自己没有亲见，然后才开口。**这份分寸原文没有明写，译文替它写了。

**其二 · 「高山」与「轨范」是同一枚循格的两个调。**

```
θā:-nə̄k kūx-nə̣m.          老师循山：已成之事。  （调 6）
gə́θ-nə̄k θā:-nə̄k-nə́m.     后人循老师：一道指令。（调 3）
```

夫子之于山，如后学之于夫子。**原文两行各说各的，译文用一个 `-nəm` 把它们串成了一条链：山 → 师 → 后人。**「轨范」在这里不是一件东西，是一个执行调。

**其三 · 「礼乐」是两道口令。**`mā:-nə́m. vrə̄m-nə́m.` 照式样做，照和鸣做。`mā:` 是模式，`vrə̄m` 是两个振动被封在一起。礼乐在夫子那里本来就是做出来的，不是摆出来的；**译文把名词化回了动作。**

### 5.6 三处倒着说

梦天语有几样东西只能从反面说。这在别处是限制，在这首诗里恰好合用。

**「至善始止」→ 未准，不许停。**

```
t'ə́s mə̀ ʔuʔ sə̀ʔ mà.
```

全语唯一的正面评价词是 `t'ə́s`（准），而它是一次判定。所以「至善」落在 `t'ə́s` 上：准就是准，没有更准。「止」是 `sə̀ʔ`（停）。句子倒过来说，**把「止于至善」读成了一条不许半途而废的戒律**。《大学》的原意正在于此。`mà` 是全篇唯一的一道禁令，它禁的是停，不是人。

**「万世太平」→ 一万代人不坏，那兆头会一直指着。**

```
nə̄k-wə̄w tūk-tūŋ gə̀ɣ mə̀ io:.
```

「太平」取 `gə̀ɣ mə̀`（没坏），与这门语言的问候同式。祝愿取模态 `io:`（终将）：座架 `io`【征】是「一件指得着的确定之事，指向一个够不着又认不出的东西」，长音加的是不终止。两个元音就是这句话走的路：`i`（眼前这位确定的老师）→ `o`（一万代以后）。**他是一个征兆，而征兆会一直指着。**比「愿万世太平」少一分把握，多一分老实。

**「不忘」→ 不至于再也认不出。**

```
ʔiāʔ uo: mə̀!
```

「忘」在梦天语里是一条路：`uo`【昧】，本来确知其在、说得出是哪一个的，如今不再认得。长音形 `uo:` 是「再也认不得」。否定它，就是不忘。**忘的不是事情，是认得它的那一下。**对「真」而言，这比「不忘」更准：真理不会丢，丢的是我们认得出它的能力。

### 5.7 一个「停」字，走了四处

`sə̀ʔ` 在全篇出现四次，两个调：

| 行 | 形 | 原文 | 义 |
|---|---|---|---|
| 一 · 8 | `sə̀ʔ mà` | 至善始**止** | 不许停 |
| 二 · 7 | `sə̣ʔ hə̄m` | 存**亡** | 停住了的，存起来 |
| 三 · 1 | `θā-nə̄k sə̣ʔ` | （增） | 教人的那个人停住了 |
| 三 · 2 | `θā: sə̀ʔ mə̀` | （增） | 言没有停 |

梦天语里人的死与工具的停是同一个词。原文的「止」与「亡」隔着四行，是两个字；译文里它们是同一个词的两个调。**增的那一联把这条线收住：他教人不许停，他把停住的东西存起来，他自己停住了，而他的言没有停。**

### 5.8 四德，四种词

```
ʔūm. friəm. nāim. ʔāiʔ.
```

| 原文 | 取 | 它在梦天语里是什么 |
|---|---|---|
| 忠 | `ʔūm` 志诺 | **应答族**：代价我担。说出即完成 |
| 恕 | `friəm` 柔让 | **理感词**：温柔封存一个反例，携带它继续前行 |
| 仁 | `nāim` 怀爱 | **大词具身态**：抱着孩子时的那一种爱 |
| 爱 | `ʔāiʔ` 爱 | **大词纯粹态**：落到一个够得着、确指的存在上 |

汉语的四个字是四个并列的名词。译文里它们分属四类：**忠是一句誓，恕是一种身体里的感觉，仁是穿了衣服的爱，爱是光着的爱。**四个词各自成句，句号断开，读起来一步比一步轻，到 `ʔāiʔ` 只剩一个被喉塞封住的元音。

「恕」对得最准：恕不是忘掉对方的错，是把它包好了带着走。`friəm` 的词典释义逐字如此。

### 5.9 把东西放在地方

梦天语没有「有」。一样东西在，就是把它和一个地方摆在一起。本篇四处用这一式：

| 行 | 形 | 原文 |
|---|---|---|
| 一 · 2 | `lō:s-nəm θā:-nə̄k.` 无岸之水中，师 | 横流启圣 |
| 一 · 7 | `mə̄t-nəm və̄l-θīh də̄m.` 手中，两端之间那一处 | 允执厥中 |
| 二 · 4 | `nə̄k-və̄l-nəm slāiθ.` 众人之中，渗爱 | 泛爱仁人 |
| 三 · 8 | `frə̄w-ɣə̄w-nəm kāl.` 花夏之中，承重的那一格 | 华夏纪纲 |

**「横流启圣」最见这一式的好处。**`lō:s`【溟】是「没有岸的水：在里面看不出方向，也不会到边」。译文不说洪水「开启」了圣人，只说那片看不出方向的水里，有一个教人的人。**因果让给了并置，而画面更静，也更大。**

「泛爱」取 `slāiθ`：流爱加一个多孔的韵尾 `θ`，词典释义「多孔无处不渗的流爱」。它不是爱每一个人，是爱渗到每一处。

### 5.10 绳墨：这一行不必翻译

```
sə̄ŋ. kxə̄l. t'ə́s.
```

线。墨。准。

三个词全在册，而且恰好是原物：`sə̄ŋ` 是线，`kxə̄l` 是「磨碎的骨，调成了液」，`t'ə́s` 是工坊里那一声判定。原文拿木工的器具比法度；**而梦天语的法度本来就是从工坊里那一声「准」长出来的，比喻在这里合拢成了字面。**

这一行用的是工序歌的句式，那是这门语言最古的文类：一词一句，句号断开。全诗从 a: 域的敬称起，到这里落回 ə 域的三样物件，再从三样物件跃到末行的两个大词：

```
sə̄ŋ. kxə̄l. t'ə́s ʔā:!        线。墨。准。
ʔoāʔ — ʔiāʔ uo: mə̀!          求——真，不至于再也认不出！
```

**先是手上的准，然后才是真。**`ʔiāʔ`（真）的释义是「手边这一个确定的事实升为普遍法则」。这两行就是那一次升。

## 六 · 增减与补注

| 处 | 动作 | 说明 |
|---|---|---|
| 三 · 1 至 2 | **增一联** `θā-nə̄k sə̣ʔ. θā: sə̀ʔ mə̀.` | 把「至圣」念出来：圣是言不终止。原文之意在题里，译文移入正文。见 5.1 |
| 三 · 3 | **增一词** `kāuŋ` | 接住「高」：够不着而确在。见 5.2 |
| 一 · 6 | **化名为事** 增 `və̄s` 两次 | 「君臣父子」四个名词，译文说出其间的关系。见 5.3 |
| 一 · 1 | **增判据** `-ei` | 传说须交代是听来的。见 5.5 |

| 三 · 9 | **减两物** 规、矩 | 绳墨在册而规矩无词。留前两件，补一个 `t'ə́s`，法度之义不失 |
| 题 | **「至圣先师」→ `θā:-nə̄k`** | 「至」与「圣」并入敬称的长音，「先师」即 `θā-nə̄k` 本身 |

**专名一律照义译，不照音**：尼丘作 `xə̄p-kūx`（土山），华夏作 `frə̄w-ɣə̄w`（花夏，华取花的本义），《春秋》作 `« θə̄w-bə̄w »`（两枚都是最古一级的季名），《易》作 `« fāf »`（变通）。梦天语的词是从体感里长出来的，照音搬一串进来，四个槽都读不出东西。

**「五伦」作 `nā-dā tīk`**：`nā-dā`【伦】词典释义是「人之道，一个方向，不是一道禁令」。五条路都在，哪一条也不压着另一条。

## 八 · 校记

**词形**　逐个在《分级词典》里查过，未跑校验脚本。两枚不在本地词典正文而有档案依据：`ʃā:`（灵性，主书第八章 · 5）与 `və̄l-θīh`（之间，《临时词账》回补第 2 级）。

**三处句式是译者往前推的，没有逐字先例**：

1. `gàs-ei`：`gàs` 档案标虚拟态，此处用于已成的传说并挂判据。
2. `ʃāʃ`【传】作谓语：它是字理词的概念形，调 1，档案未给谓语例句。
3. `X ʔəʔ Y, kāk əi:.`：判断句后项再挂模态。

**一处取词可商**：「仁」取 `nāim`（怀爱）偏于具体。这个文明自己最近于「仁」的是 `nə̄k-gā:`（人教：注意力落在人身上的那一门教），但那是一门教的名字，放不进四德的行列，故不取。

**书名加 `« »`**：正字法不许大写，书名与普通词同形，故以引号立名，照档案 `« θfā:t » ʔaʔ θə̄m.` 之例。

> **圣，在梦天语里是一个长音：言而不止。**
> **高，是一个元音：确在，而够不着。**
> **这首歌末了求的是真。梦天语把它译成了三样物件和一次升起：线，墨，准，然后是真。**
