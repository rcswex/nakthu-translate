# 梦天语（Nakthu）文体介绍之“浮艳风”

> 一门以压缩为荣的语言，也会长出一种以铺张为乐的文体。
> 它的批评者只用了一个声调，就给它定了性。

---

## 引子：一门把话说短的语言

梦天语（Nakthu）是陈文戈创制的实验性人工语言。它最出名的脾气是省。

它的哲学家说「没验出毛病不等于合格」，用五个音节：

```
gə̀ɣ mə̀, t'ə́s mə̀.
```

说「我思故我在」，也是五个音节：

```
nā stí-u: əu nā.
```

这不是修辞上的克制，是构造上的结果。梦天语的一个音节就是一个格点，起首、韵核、韵尾、声调四个槽各自载义，四样东西在一次发音里同时到达。所以它的高级文体几乎都在往密里走：哲思体压到人勉力可说的极限，满载体干脆越过了人的语速。

然而一门语言只要活得够久，就一定会有人反过来写。

本文介绍的就是那一路反过来写的东西：**浮艳风**。它把这门语言里最贵的材料一样一样摆出来，对仗工整，句子拉长，读起来像汉代的骈文，排出来却是现代诗的样子。它在自己的世界里名声不好，而它名声不好的方式很能说明这门语言是怎么想事情的。

## 一 · 先认材料

浮艳风用的全是现成的贵材料。不熟悉梦天语的读者，先认下面六样就够了。

| 材料 | 是什么 | 例 |
|---|---|---|
| **大词** | 韵核是含 `a` 的双元音的概念词。裸态说概念本身，穿上辅音就是它的某一种质地 | `ʔāeʔ` 美 · `ʃrāe` 铺满视野的美 · `gāer` 沉甸甸会回响的美 |
| **座架** | 连接词，站在它所连成分的后面 | `iu` 因 · `əu` 故 |
| **理感词** | 座架穿上辅音之后的内容词，说的是一种推理的体感 | `zliuf` 润因，不费力的懂 · `t'əuk` 铁断，结论咔哒锁死 |
| **量词** | 四枚裸的长元音 | `i:` 这一个 · `u:` 某一个 · `e:` 任一个 · `o:` 不知哪一个 |
| **循格** | 挂在词后的 `-nəm`，说「在其中、循着它」；载调 6 作 `-nə̣m`，说「如它那样」 | `kūx-nəm` 在山上 · `fə̄w-nə̣m` 如花 |
| **判据** | 挂在谓词后，交代这句话凭什么知道。梦天语的断言原则上要作证 | `-i:` 亲眼 · `-u:` 亲身 |

再认三种文体，它们是浮艳风的债主。

- **风雅体**：假装自己只有最古老的那一层词，零判据，一首诗至多一次停顿。一句话概括是「装穷」。
- **满载体**：每个内容词都是四槽全满的单音节，信息率超过人的上限。登在报纸上，没有人读得出，也没有人觉得奇怪。
- **遍格体**：句法是熟的，格点是生的，一开口就在遍历整张格点表。它原名 AGI 体。

## 二 · 定义

**年代**　维护期，第 80 年之后。满载词、遍格体、风雅体三样都已现成，它才借得到。

**门类**　文哲学科散文的一路。

**本语名**　自称 `ʔāeʔ-nə̄m`，意思是「循美的那一路」。批评者叫它 `ʔāeʔ-nə̀m`，只改了循格上的一个声调，意思就成了「唯美那一派」。

**一句话**　**把贵的词摊开来铺。**

它是「准满载体」：站在风雅体、满载体、遍格体三者的交界上，样样沾一点，而三者都不是。

| 债主 | 借了什么 | 没借什么 |
|---|---|---|
| 风雅体 | 零判据、分行、末位破戒 | 装穷。它一点也不穷 |
| 满载体 | 大词成串 | 全满载。它留着呼吸 |
| 遍格体 | 量词领句、铺排感 | 格点均匀。它只挑好听的 |

**它向三位债主各借了一样，而三位的本钱它一样也没借。**

## 三 · 家法六条

**一 · 准满载。**大词取具身态，一行两到三枚。但不许全满载：每行必须留简单词作铰链。密度很高，而永远到不了顶。

**二 · 骈对。**一行分两个半行，逐词同构，音节相等，中间一个逗号。

**三 · 长句不断。**全篇靠座架与逗号连成一句，句号只在末尾出现一次。

**四 · 理感词作比，不作判。**在论战文体里，`ʃiuh`（空因）一词就能给对手定谳。浮艳风把理感词一律挂上 `-nə̣m`，只当喻体用：像一次润因，像一次铁断。

**五 · 量词领句。**借遍格体「一个也不落」的姿态，却只点到为止。

**六 · 零判据，末位落一枚裸词。**不作证是从风雅体借来的礼，末尾那一枚孤零零的简单词是从满载体借来的收口。

**参数**

| 体 | 朴素度 σ | 满载度 ρ | 代字 | 判据 | 悬置 | 一句话 |
|---|---|---|---|---|---|---|
| 风雅体 | →1 | ≈0 | 禁 | 零 | ＝1 | 装穷 |
| 满载体 | 0 | 1 | 不适用 | 无 | 零 | 不是不可懂，是超速 |
| 遍格体 | 0 | 1 | 不适用 | 模板所带 | 模板所带 | 全格点均匀 |
| **浮艳风** | **中低** | **中高，永不到 1** | **许** | **零** | **多** | **把贵的词摊开来铺** |

## 四 · 样本：论有无

### 梦天语

```
wā:-nəm ʃrāe ʔəʔ gāer, hā:-nəm hāuɣ ʔəʔ frāum,
kūx-nəm kiāx kāuŋ-nə̣m iu, ʃə̄h-nəm siān zəā:l-nə̣m əu,
e: fāes zliuf-nə̣m, u: tiāk t'əuk-nə̣m,
slāiθ ʔi:ʔ luəɣ, guās ʔi:ʔ ləis —
ʔāeʔ dūk kə̉? — o:.
```

### 逐字译

语言分析式。一个格点一格，语法成分进方括号，不通顺是正常的。

```
宇宙[循] 广美 并 活美，虚无[循] 空畏 并 封畏，
山[循] 粗真 巨畏[如] [因]，天[循] 证真 麻醒[超越][如] [故]，
[任] 柔美 润因[如]，[某] 定真 铁断[如]，
渗爱 [恒并存] 温丧，恒志 [恒并存] 牵引 —
美 那 [疑问]？ — [不知哪一个]。
```

### 现代汉语

```
宇宙里有铺满视野的美，也有沉甸甸会回响的美；
　　虚无里有面对空无的静，也有把温柔封起来的畏。
因为山上的事实压下来像一座雪山，
　　所以天上的证明传过来像一阵电。
随便哪一种轻柔的美，都像一次不费力的懂；
　　总有那么一条定理，像结论咔哒一声锁死。
无处不渗的爱，永远和思念在一起；
　　持久的志，永远和被拽着走的感觉在一起。
那么美在哪里？
　　不知道是哪一个。
```

## 五 · 逐行读

**第一行，5｜5。**

```
wā:-nəm ʃrāe ʔəʔ gāer, hā:-nəm hāuɣ ʔəʔ frāum,
```

`wā:`（宇宙）与 `hā:`（虚无）是全语最重的一组最小对，只差第一个辅音：一个是双唇圆拢的包裹，一个是气息穿过空腔。档案说「有与无是同一次呼吸的两种含法」。浮艳风拿这一对开篇，左右各挂一枚循格，各配两枚大词。左边两枚属「美」，右边两枚属「畏」。梦天语没有「有」这个动词，「处所在前，物在后」摆出来就是「有」，所以这一行一个谓词也没有。

**第二行，7｜7。**

```
kūx-nəm kiāx kāuŋ-nə̣m iu, ʃə̄h-nəm siān zəā:l-nə̣m əu,
```

山对天，粗真（事实、经验）对证真（证明、推导），巨畏对麻醒。两个半行末尾各站一枚座架：`iu` 因，`əu` 故。这是全篇唯一一处真正的论证，而它被对仗裹得几乎看不出来。

**第三行，5｜5。**

```
e: fāes zliuf-nə̣m, u: tiāk t'əuk-nə̣m,
```

量词领句：`e:` 任一个，`u:` 某一个。理感词挂 `-nə̣m` 作喻体：像润因，像铁断。家法四与家法五在这一行同时兑现。

**第四行，4｜4。**

```
slāiθ ʔi:ʔ luəɣ, guās ʔi:ʔ ləis —
```

`ʔi:ʔ` 是合取算子的长音形，意思是「二者恒并存」。爱与思念，志与牵引，各用一枚把它们钉在一起。行末那一道两边留空的横是梦天语自己的记号，叫悬置。

**第五行。**

```
ʔāeʔ dūk kə̉? — o:.
```

前四行铺了四十二个音节，到这里忽然只剩四个。问的是「美在哪里」，答的是一枚裸量词：不知哪一个，连有没有确定的一个都不知道。全篇唯一的句号落在这里。

**数一数**　全篇四十六个音节，十六枚大词与理感词。内容并不空：它说的是有与无各有其美，事实与证明各有其重，而美本身落不到任何一处。

同一层意思，若交给以省为家法的文体，四个音节可以交代个大概：

```
wā:, ʔāeʔ. hā:, ʔāuʔ.
```

> 宇宙，是美。虚无，是畏。

**四个音节与四十六个音节之间的那四十二个，就是浮艳风。**

## 六 · 危学的判词

梦天语的世界里有一门学问叫危学（`ràx-mā:`）。它是征兆学，工作是盯着那些够不着又认不出的东西，等警报响。浮艳风广受它的批评，而它的判词只有一行：

```
« ʔāeʔ-nə̄m »? — ʔàeʔ.
```

```
« 美[循·命名] »[疑问]？ — 美[异常]。
```

> 所谓「循美」？是艳。

这一手叫篡典：把对方的名号原样引来，只动一处。这里动的是声调。`ʔāeʔ`（美）载上调 2 就是 `ʔàeʔ`，词典的释义是「美失去内里，只剩接收面」。梦天语没有独立的「丑」字，它只能说「美出了故障」；汉语的「艳」恰好落在这一格上。

**危学反对它，有一条本行的理由。**`o:`（不知哪一个）、`-nə̣m`（如）、理感词，这些在危学那里是报警用的器材：说「不知哪一个」，是在报告一处真的认不出的东西。一个文体把它们当香料撒，警报就钝了。

样本末行那枚 `o:`，正是这样用的。

所以这场争论争的不是好不好看。**在一门断言要作证、每个音节都载义的语言里，装饰不是无害的：它占用的是别人用来说真话的那几个格点。**

## 七 · 交代

照梦天语档案的规矩，凡新立的东西都要说清来历。

- **这一体是新立的。**它不在《文学与翻译汇编》文体志原有的十五条之内，档案里原先既无家法也无样本。体由语言创制者于 2026 年 11 月定义，样本照上列家法写成。
- **一枚新词也没有铸。**样本与判词所用的词，全部是《梦天语分级词典》里现成的。
- **三处搭法没有先例，尚待裁定。**
  - 大词挂循格（`ʔāeʔ-nə̄m` 及其调 2 形）；
  - 量词放在名词前领句（主书第九章明写量词的位置尚待统一裁定）；
  - 理感词挂 `-nə̣m` 作喻体。
- **第五节那句四音节的对照句**是为本文拼的，不是档案原文。

## 结语：浪费也是一种证据

一门语言若只能把话说短，它其实还没有长成。能把话说长、说得不必要、说得好看而惹人生气，才说明这套材料已经富余到可以拿来挥霍。

浮艳风就是梦天语的富余。它出现在第 80 年之后，那时格点表已经快被念遍，满载词登上了报纸，机器开始自己遍历格点。有一些写文章的人看着这满地的贵材料，决定不拿它们去说最要紧的话，只拿它们去对仗。

批评它的人说得对：警报被钝化了。喜欢它的人也有一句回嘴，藏在样本最后一行里。铺了四十二个音节之后，它问美在哪里，然后老老实实答了一句「不知哪一个」。

**一篇浮艳的文章，末了承认自己没有找到它一路在铺的那样东西。**这大概是这一体最体面的地方，也是它在一门讲究作证的语言里，唯一作了的一次证。
