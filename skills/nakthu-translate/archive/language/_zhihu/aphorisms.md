# 梦天语（Nakthu）哲理句辑

---

# 上部 · 译文六句

## 一 · 道生一，一生二，二生三，三生万物

《老子》第四十二章

```
dā: gàs tīt. tīt gàs tīm. tīm gàs tīs. tīs gàs wā-θə̄m.
```
```
道生出一。一生出二。二生出三。三生出一切物件。
```
```
道 生 一。一 生 二。二 生 三。三 生 全-件。
```

**机制**　12 词 · 13 音节 · 最高第 6 级（`dā:`）。零座架，零判据。

**选词**

- `gàs` 是致生轻动词，档案标虚拟态，「可以没有所指」，正合一句说不出凭据的创世话。句式照主书第十六章 `gā: gàs wā:`（观产生宇宙）。
- `wā-θə̄m`（万物）是照 `wā-nə̄k`（所有人）拼的新复合，未入典。

**词形里再读一遍**

一、二、三共一副骨架 `tī-`，只有韵尾在走（`t → m → s`），韵核全在 `i`（够得着、确指）。到「万物」韵核跳到 `a`，不再落在任何一件上。头一步反过来：`dā:` 的 `a:` 落到 `tīt` 的 `i`。整句是 `a: → i → i → i → a`。

## 二 · 不曰「如之何、如之何」者，吾末如之何也已矣

《论语 · 卫灵公》

```
nə̄k « mā: kə̉? mā: kə̉? » θụʔ mə̀ ʔuʔ nā mā: kả?
```
```
一个人不说「怎么办？怎么办？」，那我还能怎么办？
```
```
人 «模式 吗？模式 吗？» 说 不 则 我 模式 [切问]？
```

**机制**　10 词 · 11 音节 · 最高第 6 级。真值算子 `ʔuʔ`（则）一枚，零判据。

**选词**

- `mā: kə̉?` 是主书第九章 · 6 登记的「怎么做」，正是「如之何」。
- 「也已矣」不另译，`kả` 已经把门带上。

**词形里再读一遍**

原文的妙处是同一句「如之何」说了三遍，末一遍换了意思。梦天语只动一个韵核：前两遍是 `kə̉`（请问，答案两头开着），末一遍是 `kả`（切问，余地已经掐掉）。他不肯问的那句是开着的，到夫子嘴里关上了。

## 三 · 凡是可以说的事情，都能够说清楚；凡是不可谈论的事情，就必须保持沉默

维特根斯坦《逻辑哲学论》序

```
θā əi: ʔuʔ θā t'ə́s əi:. θā əi: mə̀ ʔuʔ θā mə̀ ui:.
```
```
可说，则可说准。不可说，则应当不说。
```
```
言 [可] 则 言 准 [可]。言 [可] 不 则 言 不 [应]。
```

**机制**　13 词 · 13 音节 · 最高第 6 级。算子 `ʔuʔ` 两枚，模态 `əi:`（可）三次、`ui:`（应）一次，零判据。

**取舍**

- **否定的位置是这句的骨。** 照主书第九章 · 3 的两式：`θā əi: mə̀` 否定的是「可」（不可说），`θā mə̀ ui:` 把「不说」放进「应当」里（应当不说）。一个 `mə̀` 换一个位置，就是原文前后两半的分别。
- **「清楚」用 `t'ə́s`（准）。** 它是全语唯一的正面评价词，而且是一个判定，比「清楚」硬，合原意。
- **「必须」取 `ui:` 而不取 `iu:`（必然）或 `mà`（禁）。** `mà` 是有人下的禁令，原文没有下令的人；`iu:` 说的是事情非如此不可，那样这句话就不必说了。这一处是译者的判断，若读作逻辑必然，换成 `iu:` 即可。

**词形里再读一遍**

全句只有 `θā` 一个实词，说了四遍，其余全是功能词。一句划定「说」的边界的话，除了「说」什么也没说。

## 四 · 我思故我在

笛卡尔

```
nā stí-u: əu nā.
```
```
我觉着〔亲身〕，所以：我。
```
```
我 觉[亲身] 故 我。
```

**机制**　4 词 · 5 音节 · 最高第 5 级。座架 `əu`（故）一枚，判据 `-u:`（亲身）一枚。

**取舍**

- **「思」取 `stí`，不取 `dlú`。** 词典里的 `dlú`【思】是「不可及而确指」，即思着一个够不到的人，是思念。笛卡尔的 cogito 是「我意识到」，包括怀疑和感知，正落在 `stí`【觉】上。全库没有第三个「想」。
- **「在」不译成词，译成一次叫名。** 末尾那个光杆的 `nā` 与 `kə̄x.`（石）同式：叫出名字就是报它在。物件只能用它自己来报自己的存在，在这一句里它成了结论。
- **判据挂 `-u:`。** 这句话的全部力量在于「这件事我拿自己的身子押上」，而梦天语恰好有一枚专说这个的判据。拉丁文要靠论证撑住的那一步，这里一个后缀担了。

**词形里再读一遍**

句子以 `nā` 起，以 `nā` 收，中间只隔一次觉和一个「故」。前一个 `nā` 是主语，要靠谓语才立得住；后一个什么也不靠。从头到尾，变的不是那个词，是它还需不需要别的东西撑着。

**交代**

`stí` 在档案里的例句都带注意对象，这里不带。依据是主书第七章 · 8「语境能找回时可省」，但无对象的 `stí` 没有先例。若要守稳，可作 `nā nā stí-u: əu nā.`（我觉到我，所以：我），多一个音节，而论证成了循环，不如原式。

## 五 · 存在先于本质

萨特

**这一句照字面译不出。**「本质」有（`ʔaʔ`），「先于」有（`pə̀m`），缺的是能当主语的「存在」。但萨特自己的解释是「人先在，然后才是什么」，这一层说得出，而且只动一个元音。

```
nə̄k, pə̀m. nāk, gə́θ.
```
```
这一副身子，在先。人那一格，在后。
```
```
人〔身〕，先。人〔格〕，后。
```

**机制**　4 词 · 4 音节 · 最高第 3 级（`nāk`）。零座架，零判据，零系词；两句都是带停顿的并列判断，与 `dīk, kə̄x.` 同式。

**取舍**

- **「存在」译作 `nə̄k`。** 眼前这一副身子，叫出名字就是报它在，与上一句末尾那个光杆的 `nā` 同一手。
- **「本质」译作 `nāk`。** 「人」那一格，不指眼前哪一个身子，是 `/a/` 化之后的概念形。
- **不用 `ʔaʔ`。** 那是本质同一的系词，一用上就等于先承认了本质，与原话相抵。

**词形里再读一遍**

两个词起首、韵尾、声调全同，只差韵核：`ə → a`。「存在先于本质」在这门语言里是一条音系事实，也是一条编年事实：这个文明先有十万年的 `ə`，第 0 天才张开嘴说出 `a`。萨特要论证的那件事，在这里是历史。

**交代**

- 这句说的只是「人」。萨特的命题本来也只对人成立，所以不算缩水；若要泛指一切物，可改用域名：`ə̄, pə̀m. ā, gə́θ.`（具象那一域在先，概念那一域在后）。两个域名档案有，这个句子是新拼的。
- `pə̀m`、`gə́θ` 作判断的后项，没有逐字对应的先例，依据是它们在档案里本可独立成段（`kə̄x-tə̄k gàs, gə́θ.`）。

## 六 · To be, or not to be, that is the question

莎士比亚《哈姆雷特》

```
sə̀ʔ mə̀ ʔoʔ sə̀ʔ kả?
```
```
不停，还是停？这一问没有人替我答。
```
```
停 不 [抑] 停 [切问]？
```

**机制**　5 词 · 5 音节 · 最高第 9 级（`ʔoʔ`）。真值算子一枚，零判据，零主语。

**取舍**

- **「to be」译作 `sə̀ʔ mə̀`（不停）。** 梦天语没有「在」这个谓词，而哈姆雷特这一句问的是活还是死。词典里「死」就是 `sə̀ʔ` 的完成形 `sə̣ʔ`（停住了），人的死与工具的停是同一个词。所以「活着」只能说成「没停」，与「好」只能说成「没坏」是同一条。
- **「or」取 `ʔoʔ`，不取 `ʔeʔ`。** `ʔeʔ` 是两样都够得着、都要也行；`ʔoʔ` 是恰好一个为真，而不知道是哪一个。哈姆雷特的处境是后一种。长音形 `ʔo:ʔ`（二者取一而永不揭晓）更重，但那是深渊域，等于替他判了永远想不出，故不用。
- **「that is the question」不另成句，压进 `kả`。** `kả` 是切问：余地已经掐掉，只等你亲口填上。换成普通的 `kə̉` 就成了一句向人打听的话；用 `kả`，这一问便只能由问的人自己答。原文后半句说的正是这个。
- **不立主语。** 原文是不定式，谁也没说；梦天语可以整句无主语，正好照搬。

**词形里再读一遍**

原文先说肯定的 to be，再加一个 not。译文倒过来：否定词落在「活」那一边，「死」那一边是光杆。在这门语言里，活着是带标记的那一项，要多花一个 `mə̀` 去撑；停下来什么也不用加。五个音节里，`sə̀ʔ` 出现两次，句子从停开始，到停结束，中间那个 `mə̀` 是唯一把它们隔开的东西。词典在 `mə̀` 条下写的是「全语最要紧的一个字」。

**交代**

`ʔoʔ` 连接两个光杆谓词、句末再挂 `kả`，这个组合没有逐字的先例。依据是主书第十二章 · 12「两个方案恰好选一个用 `ʔoʔ`」与第九章 · 6 的两级问。

# 下部 · 梦天语的哲学家怎样谈「存在」

**他们不问「存在是什么」，因为这句话在梦天语里拼不出来：没有一个谓词可以放在「是什么」前面。** 这个问题于是被拆成四个各自说得出口的问题。这门学问叫 `dā:-gā:`（道-观，形而上学）。它的名字里是「观」，不是「有」。

## 一 · 有与无：一组最小对

```
wā:   宇宙      w 圆拢包裹 ＋ a: 零限定·不终止
hā:   虚无      h 气息穿空腔 ＋ a: 零限定·不终止
```

主书第八章 · 6 称它「全语最重的一组最小对」，并说「有与无是同一次呼吸的两种含法」。哲学家谈「有」，谈的是 `wā:`：一切在的东西的总和，是个名词。能对它做的断言只有两种：

```
wā: mə̀ ʔaʔ hā:.        有，在本质上不是无。      （强同一的否定）
nā: ʔa:ʔ wā:.           合一的我，与宇宙融为一体。 （主书第十六章原句）
```

第一句是照 `nāk mə̀ ʔaʔ nə̄k.` 拼的，第二句是档案原文。

## 二 · 「X 存在吗」：改问「凭什么报它」

没有存在谓词，存在主张只能经一次认识报出来，而认识必须挂判据。所以本体论的争论在这里自动变成认识论的争论：

```
nā nā stí-u:.                        我亲身觉到我。
t'ə̄uk-nəm və̄s, mə̄t-nəm mà.         循推证接得上，手上不可及。
```

第一句照 `nā dīk stí-u:.` 的单对象框拼成。第二句是汇编原文，说的是「超小之物」：它在，而它的在只有一条推理的线接着。

韵核与判据合起来，给出一把分级的尺子，从「在此」到「连有没有都不知道」：

| 层 | 手段 | 读作 |
|---|---|---|
| 在手边 | 韵核 `i` · 判据 `-i:` `-u:` | 指得到，验过 |
| 确知其在而够不着 | 韵核 `u` · 判据 `-əu` | 只接得上一条推理 |
| 不知有没有 | 量词 `o:` · 判据 `-o:` | 在报告，而说不出凭什么 |

哲学家之间的分歧，是一样东西该落在这张表的哪一行，不是它「有」还是「没有」。

## 三 · 「有从哪里来」：观生出宇宙

```
gā: gàs wā: əu wā: gā: gàs nā:.
观产生宇宙，于是宇宙看回来，看出了那个与它合一的我。
```

这是主书第十六章的「哲学之链」。它是这个文明的正统立场，也是人教（`nə̄k-gā:`）的底：先有注意，后有世界。「存在即被观」在这里不是一个学派的主张，是致生动词 `gàs` 两边各放一个名词就得出的句子。

## 四 · 「为什么有而不是无」：问得出，答不出

```
wā:, hā: mə̀. iu kə̉?
是宇宙，不是虚无。因，何？
```

这句是新拼的：前半是普通类别判断加否定，后半照主书 `əu kə̉?` 的式子，引一枚座架来追问。它问得出来；而答它要给 `wā:` 找一个原因，原因得在 `wā:` 之外，`wā:` 之外只有 `hā:`。面对这一格，档案留的不是论证，是一个词：`hāuɣ`（空畏，面对空无，死亡之前的静）。

## 说不了的那一句

「存在先于本质」照字面译不出，缺的是能当主语的「存在」：`wā:` 是全体，不是「在」这件事。一个梦天语哲学家会说这句话没有说完，要你补上是谁、在哪里、凭什么。这正是那一格空着的代价，也是它的用处。绕过去的译法见上部第五句。

---

这五句都不是从别处译来的，是顺着这门语言自己的构造往前推一步得出的话。

## 一 · 论真

```
ʔiāʔ-nəm mū:k mə̀ ʔuʔ ʔiàʔ.
```
```
真〔循〕 体证 不 则 妄。
```
> 一句真话里若没有拿身子押上的那一份证，它就是妄。

- **构造**　前半是处所＋物＋否定，即「真里头没有体证」；`ʔuʔ` 是蕴含。
- **惯性在哪**　`ʔiāʔ`（真）与 `ʔiàʔ`（妄）只差一个声调，调 2 是「出了故障」。这句话说的是那个故障出在哪里：缺一份证。

## 二 · 论因

```
« iu » wā-θə̄m-nəm və̄s ʔuʔ ʃiuh.
```
```
「因」 全-件〔循〕 接 则 空因。
```
> 一个「因为」若在什么东西上都接得上，它就是空的。

- **构造**　裸座架不能直接入句，所以加引号引用它；`və̄s` 是「接得上」。
- **惯性在哪**　`ʃiuh` 是 `iu` 穿上辅音的具身形，`ʃ` 弥散、`h` 中空。词典给它的释义是「弥散于一切处、内里中空的理由」。这句话是把那个词的两个辅音各念成了一个分句。

## 三 · 论爱、美、畏

```
ʔāiʔ, i:. ʔāeʔ, e:. ʔāuʔ, u:.
```
```
爱，此。 美，任。 畏，某。
```
> 爱要的是这一个。美，哪一个都行。敬畏朝着的，是确有而够不着的那一个。

- **构造**　三个带停顿的并列判断，后项各是一枚量词。
- **惯性在哪**　三个大词的韵核是 `āi`、`āe`、`āu`，三枚量词是 `i:`、`e:`、`u:`。每个大词的后半个元音，就是它自己的量词。这句话什么也没有主张，它只是把三个词各念了两遍。

## 四 · 论我

```
nə̃k ɣə̀s. nā stí. nā: gā:.
```
```
我〔工具〕 做。 我〔人〕 觉。 我〔合一〕 观。
```
> 当工具使的那个我，在做。作为人的那个我，觉着。合一的那个我，只是看。

- **构造**　三个主谓短句，零座架，零判据。
- **惯性在哪**　三个「我」是同一个词走了三层（`ə → a → a:`）。配上的三个动词一层比一层少一样东西：`ɣə̀s` 改动对象，`stí` 只取对象，`gā:` 连判定也不下。

## 五 · 论好

```
gə̀ɣ mə̀, t'ə́s mə̀.
```
```
坏 不， 准 不。
```
> 「没坏」不等于「合格」。

- **构造**　与 `dīk, kə̄x mə̀.`（这不是石头）同式，只是前项换成了一个否定短语。
- **惯性在哪**　这门语言没有「完好」一词，问候只能说「没坏」；而它唯一的正面评价 `t'ə́s` 是一次判定。两条设计各自立在词典里，这句话是头一次把它们并排放。五个音节，两个 `mə̀`。
