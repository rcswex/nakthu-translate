# 语法速查卡

**这是速查，不是权威。** 权威是 `language\_grammar_book\梦天语词法手册.md`（成熟梦天语）与词典。下面每一条都能在手册里找到；拿不准就 `Grep` 手册对应节，别靠这张卡硬写。

## 一、音与形

| 项 | 规则 |
|---|---|
| 四个槽 | 起首（辅音或簇）· 韵核（元音，可双元音、可长）· 韵尾（可空，可成簇）· 调 |
| 一格一音节 | 书写单位＝音节。多音节必带连字符。三种接法：复合／语域前缀／零调附着。转写里看不见连字符，就是原子 |
| 六调 | 1 平＝命名 · 2 沉＝异常（引申：禁止）· 3 锐＝执行（引申：命令）· 4 问＝疑问 · 5 跌＝紧急 · 6 重＝完成（引申：终结）；零调＝附着成分或关系小词 |
| 叫喊调 | `◌̂`，不入调系：`ʔə̂!` `ʔâ!` |
| 元音二轴 | `i` 可及·确指 · `u` 不可及·确指 · `e` 可及·不确指 · `o` 不可及·不确指 · `ə` 原点 · `a` 零限定。**长音只加「不终止」** |
| 标调位置 | 声调标于韵核中开口度最大者；含 `a` 者一律标 `a` |
| 记号 | `,` 分句／话题界 · `.` 句界 · `…` 有事在发生（`ʔōm…` 的省略号强制）· `—` 悬置，修辞性沉默（报数框架界除外）· `« »` `‹ ›` 本语引语 · `〔 〕` 判据汉译的译者补注 · `:` 只作长音 |
| 复合 | 中心语在末位：`kə̄x-tə̄k` 石刀＝一种刃 |

## 二、词类认形

| 看到 | 多半是 |
|---|---|
| CVC，调多样 | 名词／动词／状态词（三问：能单说答「这是什么」＝名词；主语后要停顿＝名词；能否接判据；要不要对象） |
| 起首成簇、无韵尾、单元音 | 动词 |
| 起首成簇、有韵尾、`ə` | 名词 |
| 喉塞夹双元音 `ʔVVʔ` | 大词（概念）：`ʔāiʔ` 爱 · `ʔāuʔ` 敬畏 · `ʔāeʔ` 美 · `ʔāəʔ` 赋 · `ʔəāʔ` 觉醒 · `ʔiāʔ` 真 · `ʔuāʔ` 志 · `ʔeāʔ` 慧 |
| 辅音夹含 `a` 双元音 | 大词（具身）：`tāik` 爱之精确 |
| 辅音夹不含 `a` 的双元音 | 理感词（`zliuf` 润因、`kiuk` 重因、`ʃiuh` 空因、`θəok` 虚压、`friəm` 柔让…） |
| 光杆双元音 | 座架 |
| 起首簇＋双元音＋韵尾簇 | 满载词 |
| `ʔVʔ` | 真值算子 |

## 三、句

| 构式 | 形 |
|---|---|
| 及物陈述 | `A B gə́s.` A 检查 B（SOV）；简单句可 SVO，拙朴 |
| 不及物 | `A də̄x.` |
| 否定 | `A B gə́s mə̀.`；动作句前置 `mə̀ gə́s` 为强调；名词判断后置 |
| 禁止 | `A, ɣə́ʃ mà!` / `A, ɣə́ʃ mə̀!`（别添火） |
| 类别判断 | `dīk, kə̄x.` 这是石头；`dīk, kə̄x mə̀.` 这不是石头；`dīk kə̄x` 无停顿＝名词短语「这块石头」 |
| 强同一 | `dīk ʔaʔ kə̄x`（本质上就是）；`dīk mə̀ ʔaʔ kə̄x` 本质上并不是 |
| 存在／处所 | `dīk-θīh-nəm lə̄s.` 这里有水；否定后置 |
| 疑问 | 句末 `kə̉`：`A B gə́s kə̉?`；词内调 4 问那一个词；`dūk kə̉?` 哪里；`nə̄k kə̉?` 谁；`θə̄m kə̉?` 什么；`kả?` 切问 |
| 过程小词 | `-lə́` 进行 · `-lə̀` 受阻 · `-lə̣` 完成 · `-lə̄` 过程名称 · `-lə̉` 问进行 · `-lə̃` 催促 |
| 频度 | `də̄w` 一遭 · `dīw` 常 · `dūw` 偶 · `dēw` 不时（比较各次事件之间） |
| 并列 | `ʔəʔ`（纯并列）；并置本身不建立因果 |
| 变调族（以 `və̄s` 接 为例） | 1 接 · 2 `və̀s` 接断了 · 3 `və́s` 修 · 4 `və̉s` 还接得上？ · 5 `və̃s` 快接上！ · 6 `və̣s` 接上了 |

## 四、人称与指示

`nā` 我（主体性）· `nə̃k` 我（行动的身体／工具自我）· `nā:` 合一自我 · `nī` 你（现行；旧 `tə́k` 仅供旧文）· `sə̀k` 他／她／它，也可自指 · `dīk` 这（够得着）· `dūk` 那（够不着）· 复数 `-və`（也可表不明确数量）· `nə̄k-və̄l` 众人 · `wā` 全部 · `wā-nə̄k` 所有人。

## 五、数

`tīt` 1 `tīm` 2 `tīs` 3 `tīn` 4 `tīk` 5 `tūt` 6 `tūm` 7 `tūs` 8 `tūn` 9 `tūk` 10 `tīŋ` 百 `tūŋ` 千；`tə̄ŋ` 阶（千的方次）。数词置于名词之后：`nə̄k tīt` 一个人。日常大数千进，不借汉语万进。数词调：3 付、2 欠、6 清（记账语）。

## 六、关系成分

**座架**（分写，跟在所连前一段之后）：`iu` 因 · `əu` 故 · `iə` 虽 · `əi` 为 · `ei` 即 · `ui` 例 · `uə` 丧；含 `o`：`io` 征（意味着）· `uo` 昧 · `eo` 遁 · `əo` 万一 · `oi` 认 · `ou` 原 · `oe` 表 · `oə` 怅。
**模态**（座架的长音形，站谓语上）：`iu:` 必然 · `iə:` 纵然 · `əi:` 可能 · `ei:` 确认 · `ui:` 应当 · `əu:` 必然导致 · `uə:` 不复；含 `o`：`io:` 终将 · `uo:` 再也认不得 · `eo:` 追不回 · `əo:` 始终有可能 · `oi:` 终会认出 · `ou:` 原来一直是 · `oe:` 永远只到表面 · `oə:` 乡愁。
**量词**：`i:` 这一个 · `u:` 某个 · `e:` 任何 · `o:` 不知哪一个 · `wā` 全部。
**真值算子**（封在两个喉塞之间，分写）：`ʔaʔ` 同一 · `ʔiʔ` 合取 · `ʔuʔ` 蕴含 · `ʔeʔ` 相容的或 · `ʔoʔ` 排他的或 · `ʔəʔ` 并列；长形加「不终止」。
**判据**（零调连写）见 SKILL.md；具身形名词如 `mī:k` 视证、`mūik` 试证、`mə̄uk` 推证。
**信息结构**（零调连写，说「你那里有没有它」）：`-əe` 入 · `-ie` 解 · `-ue` 取 · `-eə` 退 · `-eu` 延；长形加「不终止」（`-eu:` 穷＝一个不落，`ʃə̄ɣ-eu:` 每一日）。判据与信息结构不叠在同一成分上。
**循格** `-nəm`：循着、按着、在其中。同一枚是方位、语域开关、寒暄（`nə̄k-nəm` 你好）。载调形：`-nə́m` 照 X 来做 · `-nə̣m` 已经是 X 那样了 · `-nə̄m` X 派 · `-nə̀m` X 主义 · `-nə̉m` 是不是循 X。比较：`X-nəm` ＝以 X 为准。

## 七、否定与量化的位置（最易错）

| 想说 | 写 |
|---|---|
| 从来没去过 | `ʃə̄ɣ-eu:, sə̀k də̄x mə̀.` |
| 不是每次都去 | `ʃə̄ɣ-eu: mə̀, sə̀k də̄x.` |
| 你不必碰 | `nī … dēt ui: mə̀.` |
| 你应当不碰 | `nī … dēt mə̀ ui:.` |
| 禁止你碰 | `nī … dēt mà.` |
| 水没有坏（实测） | `lə̄s mə̀ gə̀ɣ-ui.`（否定在判据之前） |

## 八、对话层

**应答族**（说出即完成，不描述世界）：`ʔēm` 我听到了、正在权衡 · `ʔīm` 我确认为真 · `ʔə̄m` 我明白了、我接 · `ʔūm` 这份代价我来担 · `ʔām` 圣诺（礼仪级一诺）· `ʔōm…` 我听到了但还答不上来（省略号强制）。对自己发诺叫立誓。
**叹词**：`ʔā!` 纯粹开放之叹 · `ʔā:!` 长叹，一口气吐到尽 · `ʔə̀!` 噫／卡壳 · `ʔâiʔ!` 不由自主的喊。
**寒暄八句**：`ʔə̂!` 碰见生人 · `ʔâ!`＋名 碰见熟人 · `kả?` 线上呼叫 · `ʔâ!` 应答 · `nə̄k-nəm.` 你好 · `nə̄k-və̄l-nəm.` 大家好 · `gə̀ɣ mə̀.` 没关系／我没事（本语不说「我很好」，说「没坏」）· `ā:-nəm.` 谢。
**敬称**：长音。去韵尾敬人，留韵尾敬事（`t'ā:` 敬他，`t'ā:s` 敬他做的事）；CCV 动词只有一级；不给亲属词与性别称谓造敬称。

## 十、几个常用的「弯」

完好 → 本语不说「很好」，说 `gə̀ɣ mə̀`（没坏）· 白 → 雪 `θə̄f` · 黑 → 夜 `ʃə̄m` · 西风 → 远风 `hūθ` · 人家 → `nə̄k-ɣə̄ʃ`（人之火）· 昏鸦 → `ʃə̄m-pə̄t`（夜之鸟）· 桥 → `lə̄s-θə̄x`（水—木）· 断肠人 → `ràx-nə̄k`（隐裂之人）· 庸人自扰 → `θəok`（虚压）· 向往 → `āo`（够不着也说不出是哪一个；指得出的就不该用）。使用前仍须 `lookup` 复核。
