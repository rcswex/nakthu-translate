# 翻译手艺：汉 → 梦天语

出处：《文学与翻译汇编【上册】》卷头与第二部，《词法手册》六 · 2 文体，及两篇范文《遇到》《至圣先师歌》的译笔。本卷把「信、达、雅」落成可操作的步骤。

## 一、两定律与三步

1. **本语的词永远不能逐词对译**——词形编码路径，路径无一相同。
2. **本语的词永远可以被译出**——落点是共享的。

两条一起念：路径换不了，落点换得了。

**汉 → 梦天语**（本语这一端不递现成词，只递坐标）：

```
一 认落点        汉语的词早把自己的弯磨平了（「医」不再是巫医之器），落点要自己认
二 定层 · 定域 · 定调 · 定判据     ＝ 在本语里配出那条短弯
```

**最短的弯**：本语押在「母语者当场读出一个新词的语义」上，所以弯必须短到一次工作记忆刷新内走完。自然语言的词源可以任意绕（因为没人去走），本语的词源是可读性的约束。

## 二、信、达、雅

### 信：不得替原作作证

汉语没有判据，译者因此被迫替原作做决定。**定则：默认零判据，加判据须有据**——只有当原文明言「我见」「亲历」「尝闻」，或颂诗须交代传说不在场（《至圣先师歌》首行 `-ei`）才挂。擅自加判据，是这个方向最大的越权。

其次：**意象照翻**。五禁例是封闭清单，清单之外不得替换意象。检验问一句：*我是在给这个意象找词，还是在拿一个概念把它换掉？* 膨胀允许，替换不允许。

再次：**增减要明写**。增一联、增一词、减专名、化名为事，都记进「增减与补注」，并说明理由（见《至圣先师歌》§六）。

### 达：膨胀是选择性的

| | 汉语 | 梦天语 | 方向 |
|---|---|---|---|
| 抽象词 | 愁、道、气（1–2 字） | 一个大词或长音（一音节） | 压缩 |
| 具象词 | 古道（2 字） | `kə̄r-də̄x-xə̄p`（3 音节） | 膨胀 |

接受译文在意象处变长、在思辨处变短。抗拒这一点，两头都会失真。

### 雅：定域即定命

一旦定为风雅体，就再不许出现系词。定域不可逆——定错了，后面每一个字都在错误的规则下写成。

## 三、四步法

**1 定层（α）** 汉语每个抽象词裁定落在 ə／a／a: 哪一层。

| 汉 | ə 层 | a 层 | a: 层 |
|---|---|---|---|
| 道 | `də̄x` 去 | `dā` 前往 | `dā:` 道 |
| 我 | `nə̃k` 工具自我 | `nā` 人性自我 | `nā:` 合一自我 |
| 做 | `ɣə̀s` 做 | `ɣā` 创造 | `ɣā:` 造化 |
| 看 | `gə́s` 检视 | `gā` 观看 | `gā:` 观 |

**保守定则：汉诗的抽象词一律取最低可用层。** 古人不说超越语；把「道」译成 `dā:`，一首唐诗就成了第三阶之后的作品。

**2 定域** 由题材与姿态定文体，家法随之生效（见下表）。

**3 定调** 汉语手法的梦天语着落：

| 汉语手法 | 梦天语着落 |
|---|---|
| 事件叠字（点点、声声、行行） | 象似重复：二连（有界）、三连（无界），无四连 |
| 状貌叠字（依依、萧萧、踽踽） | **不译作重复**。交给叹词、调、判据，或改写为事件 |
| 平仄 | 六调弧（调 2 沉 → 3 执行 → 6 完成 → 1 收束） |
| 对仗 | 同构复合词并置（同起首或同韵尾） |
| 用典 | 逐字引正典例句 |

叠字例：渔火点点聚散 → 「点点」弃数附着 `-və`，「聚散不停」三连；欸乃声声 → 二连（拟声不受节制律）；路漫漫 → `də̄x, də̄x, də̄x`（汉语重复状貌，译文重复动作）；踽踽三千载 → 不重复；缀着零星白帆 → 数词 `tīm θə̄f-hwə̄p`；太缓慢（程度）→ 叹词 `ʔāi! sluəʔ.`；齐桅杆 → 全称 `wā θrīp`。

重复三条：**全同**（串中每项相同）、**裸露**（不夹修饰、判据、座架、论元）、**独占一位**（前后不拖尾巴）。顶真是链、重复是长度、排比是名单，三者不混。

**4 定判据** 默认零。

## 四、五禁例

| 汉语成分 | 禁 | 应作 |
|---|---|---|
| 农业隐喻（培养、播种、根源、深耕） | 直译 | 转写为工艺／体感隐喻（打磨、敲开、试手、底面、来处） |
| 罗盘方位（东西南北） | 生造方位词 | 交给向度轴：近 `i`／远 `u`；或日出处 `ɣə̄r-θīh`／日落处 `ʃə̄n-θīh` |
| 颜色词（白、黑、红） | 生造色词 | 以物代色：白＝雪，黑＝夜 |
| 情绪抽象名词（愁、恨、断肠） | 用大词硬凑 | 八大词无负轴，须**移位**：负面落在某样正面东西的故障上（例：断肠人 → `ràx-nə̄k` 隐裂之人） |
| 数目 | 借用汉语数系 | 手系；日常大数千进 |

五禁例是代价清单，不是禁忌清单：译文里的每一处损失都要记进损失清单。

## 五、禁语与「弯」的写法

禁止写「本语说不出 X」「本语没有 X」。改写为：

> 本语说 X 要拐一个弯。那个弯的形状是＿＿。拐完之后，意思变了＿＿。

例：「那边好像有点什么」——汉语的含糊落在「什么」上，本语只能说「那边有一样东西」再挂直觉判据 `-iu`；含糊从所指搬到了证据。

损失清单记的从来不是「本语说不出」，而是「这一次我没能把那个弯配出来」。**账记在译者头上。**

## 六、文体选择表（二十二体，常用的在前）

一首诗只有一个基调：「融合」发生在词上，不发生在段上。词域漂移的四法：层升／算子／单枚满载／大词具身态与理感词（升）；层降／化石征用／声训新铸／局部零判据（降）。

| 原文类型 | 首选文体 | 要点 |
|---|---|---|
| 山水小令、咏物短章、白描 | **风雅体** | 并列即断言，禁系词禁座架；零判据；`a` 只许入叹词与终词；全诗唯一一枚满载词留末位；至多一个悬置，与终词同处；工艺隐喻，禁农事隐喻，禁直陈「美」；声训特权（可占空格点，须逐条标出） |
| 当代抒情、情歌、叙事诗 | **全盛期文学体** | 系词、座架、判据、模态、叹词阶梯、应答族全在岗；代字许；满载词作尖峰不作段落；靠座架连缀长句而不是句号断开 |
| 致一个人的告白 | **情诗** | 第二人称 `nī`；判据句句挂在谓语上，是告白的引擎；直取 `ʔāiʔ`；悬置至多一次；末行否掉检视 |
| 颂、赞、祭 | **颂诗体** | 零判据（传说须交代时例外并说理）；ə 托举 a:；叹词是结构的铆钉；核心句式 `X gàs Y`；悬置不受约束 |
| 格言、警句、箴言 | **智慧经典** | 阵列词间织入简单词：锚（本名）、空管道（被问一次的裸座架）、纯粹态签名（裸 `ʔāiʔ`） |
| 杂文、论战、锐评 | **评鉴体** | 判据不对称分配：贬敌 `θụʔ-ei`，立己 `-u:`；理感词作判决（`ʃiuh` 空因）；篡典；光杆即呐喊；悬置至多两次 |
| 论说、学术 | **学术散文** | 判据只朝外；事化叠用（代价：事化后挂不上判据）；座架承担论证；结句可退回请问 |
| 哲思短句 | **哲思体** | 不用「因为」，把因说成哪一种（理感词）；格言是主场 |
| 劳动、工序、配方 | **工序歌** | 时序即结构；零判据；长度由三连承担；句号是唯一间隔 |
| 账目、清单 | **记账语** | 数目在音段，动作在声调；不成句 |
| 公告、规程、技术说明 | **技术语域** | 禁代字（新物首次命名许一次）；凭据并排；报数到小数第一位，位数前置，`—` 是规程 |
| 素朴到拒绝 | **拙古** | 零新铸、零代字、零悬置；不用满载词；素朴是拒绝不是品味 |
| 笑话 | **笑话** | 不用满载词；复述各挂传闻；按中心语顺着查；笑点落在最后一个音节 |
| 铺张华丽 | **浮艳风** | 大词具身态成串；骈对；理感词作比不作判；零判据 |

其余各体（礼拜语域、集句、接之经、密度诗、单词诗、观之经、满载体、遍格体）及家法细则，查词法手册「六 · 2　文体」。

**同是零判据，理由不同**：工序歌是不必要（石头就在手里）；风雅体是礼（不作证的礼）；拙古是道德（不肯把判据用成兵器）；接之经是挂不上（梦没有来路）；观之经、满载体是没有那条距离。

## 七、铸币权与代字

- **声训新铸**＝念到一个还没有人念到的格点；硬判：四槽读下来就是它的意思。风雅体与全盛期文学体许可，且须在铸词表里逐条标出，读者有权自己数。
- **代字**是给一个已有本名的东西另起一个描述（增辅、抽骨、纯代）。判据机械可执行：中心语居尾，看最后那个词素是不是所指的类名。
  - 不得以代字译一个原文用本名说出的东西，除非该文体许可代字且原文本身在掉书袋；
  - 译技术、工序、记账、危机、拙古，一律用本名或限定复合，宁长不雅。
- **老词加一个辅音**是维护期铸词的实况：`lə̄s` 水＋b → `blə̄s` 鱼；`sə̄ŋ` 线＋r → `srə̄ŋ` 琴；`kə̄l` 骨＋x → `kxə̄l` 墨。词形是新的，词根是旧的，读者听见两层。

## 八、专名与特殊成分

- **专名照义译，不照音**：尼丘 → `xə̄p-kūx` 土山；华夏 → `frə̄w-ɣə̄w` 花夏；《春秋》→ `« θə̄w-bə̄w »`。梦天语的词从体感里长出来，照音搬一串进来，四个槽都读不出东西。
- **书名与被引用的名字**用 `« »`，正字法不许大写，故以引号立名。
- 外来的、暂时读不懂的形式：闭引号后挂 `-ʃroθ`（元语言标记，四槽不供货）。
- 语气词「兮」之类不载义的一口气：取叹词 `ʔā:!`（纯粹开放之叹）。
- 方位：本语没有空间的前后内外，用处所构式 `X-nəm`（在 X 之中）；时间词 `gə́θ`（之后）可借作空间时须在损失清单里写明。

## 九、损失清单的写法

每篇末尾必须开一份，三列：原文｜回译｜损失。写法：

- 写具体的弯，不写「说不出」；
- 区分「禁例所致」「语法所致」「译者没配出」；
- 例（《天净沙》）：老树→纹树，「老」的人类投射没了，只剩木料的物理状态；西风→远风，罗盘方位降为向度；断肠→裂，见「末行的墙」。

判据与音节的账：判据不占句法位，但占音节。歌行的行长固定，所以这门语言写歌，每一行都要先付一笔凭据的税。

## 十、两篇范文的译笔摘要

**《遇到》（情歌）**——「专属」不是形容词，是一个格（`X-nəm`＝以 X 为准）；比较级不必新造成分（「比谁都更明白」＝以全部人为准，我确认）；「炫耀」被一枚判据接住（`wā-nə̄k gə́s-i: ui:`：所有人都应当亲眼看见）；「庸人自扰」用理感词 `θəok`（虚压）；「不会放掉」不加重语气，把已发生的一握事化封口（`və̣s uə: mə̀`，封口之后不挂零调）；「向往」`āo` 正确地没有出现（这首诗指得出，是找到了的诗）。

**《至圣先师歌》（颂）**——「圣」是一个长音（言而不止），不是「更高」；「高」是够不着（`kāuŋ`，不是位次）；「君臣父子」化名为事（两对用同一个谓词 `və̄s` 接）；十二个「兮」全留作 `ʔā:!`；「语气落在槽里」表（传说→判据，始→调 6，行遵→循格调 3，可→模态，不忘→模态＋否定）；三处倒着说（止于至善→未准，不许停）；「绳墨」一行不必翻译（线。墨。准。）。
