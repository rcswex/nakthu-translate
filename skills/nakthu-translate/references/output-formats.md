# 输出格式

三种模式、一份新铸词列表。体例取自两篇范文：`archive/language/_zhihu/遇到_梦天语译.md`、`archive/language/_zhihu/至圣先师歌_梦天语译.md`。词形以词典为准，不以范文为准（范文里 `tə́k` 作「你」是旧写法，现行 `nī`）。

## 一、默认模式：梦天语 · 逐字译 · 落点读

按原文的节（或自然段）分块，每块一个代码块，三层逐行对齐。节序号用 `〔一〕〔二〕`；单句、单段文本不加序号。

````
〔一〕
梦天语  nā-nəm ʔûm.
逐字    循我〔志诺·叫喊调〕。
落点    以我为准，我担下这个价。

梦天语  iu nā-guās nā gə́s-u:.
逐字    因为 我—恒志 我 检视〔亲身〕。
落点    因为我一直朝着的那个方向，我自己亲身看得见。
````

写法：

- **梦天语**：一行一句，按原文行式；句号、逗号、`—`、`…` 照档案记号。
- **逐字**：一词一译。复合用「—」连接素（`kə̄x-dā-gə́θ` → 石—道—之后）；判据、调的操作、附着用 `〔 〕` 标出（`〔亲眼〕` `〔事化〕` `〔悬置〕` `〔志诺·叫喊调〕` `〔长叹〕`）。逐字读起来必然生硬，不要润色。
- **落点**：把这一句**真正指着的东西**用通顺汉语说一遍。不还原成原文，也不比梦天语多说一个字；原文的修辞若丢了，不要在这里补回去。

之后给不超过五行的「译注」（可选）：关键的弯一条、最大的损失一条、新铸词数量与登记路径。例：

```
译注  「炫耀」没有词，用判据 `ui:` 接住：让每个人都拿到「亲眼」。
损失  「街角」丢了：本语没有空间的前后内外，借时间词 `gə́θ`。
新铸  ✧ 3 枚，已登记 → _temp/新铸词列表.md
```

## 二、`-only`：仅梦天语

只给一个代码块。行式与原文对应，节间空一行，不带序号、逐字、落点、译注。若有新铸词，代码块之后加唯一一行：

```
✧ 新铸词 3 枚，已登记 → _temp/新铸词列表.md
```

题目如需译出，作代码块第一行（如 `θā:-nə̄k-θreā:m ✧`，✧ 标示临时词）。

## 三、`-doc`：文档模板

必守：

- 「五 · 译解」中每一个论断，必须能在词典、词法手册、主书或汇编里指到出处；拿不准的写进「八 · 校记」。
- 「七 · 临时词表」与 `新铸词列表.md` 里本篇登记的词一致。
- 行文克制：结论句用粗体，不堆装饰；副标题可用「——」。
- 回报：文件路径、新铸词数、校验结果三句话，不贴全文。

## 四、新铸词列表

路径：`_temp/新铸词列表.md`（实际位置以 `nakthu_lex.py where` 为准）；由 `scripts/nakthu_lex.py coin` 维护，不手改行。结构：

```
| ✧形 | 构成（逐槽或构拟） | 义 | 类 | 级 | 首见（篇目·日期） |
|---|---|---|---|---|---|
| ✧ `xə̄p-kūx` | 土＋山 | 尼丘 | 专名 | 1 | 《至圣先师歌》·2026-11-21 |
```

- **类**：复合 · 专名 · 变调 · 变核 · 声训新形。
- **级**：由形算出，取最晚一项资源。
- 同形同义再登记＝追加「首见」；同形两义＝拒绝。
- 与《临时词账》的关系：本列表是译写过程的暂存。真缺的词挑出来标 ✦ 候选，交词典编委；其余留在本表。

## 五、示例：同一句的三种输出

原文：「这么久了我就决定了」

默认：
```
梦天语  də̄x də̄x də̄x — və̄s.
逐字    去 去 去〔悬置〕接合。
落点    走，走，走——接上了。
```
`-only`：
```
də̄x də̄x də̄x — və̄s.
```
`-doc`：该句进入「二 · 梦天语译文」「三 · 逐词直译」「四 · 落点读」，并在「五 · 译解」写一条：三连的无界（久到数不清）顶住了「这么久了」，而「久到我以为不会了」需要反事实，放进去就破了歌行（记入「三处译不过去的」）。
